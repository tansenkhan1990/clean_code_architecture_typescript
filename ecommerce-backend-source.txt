```dockerfile
# syntax=docker/dockerfile:1

# 1. Install every dependency (including dev) for the build.
FROM node:22-alpine AS deps
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci --no-audit --no-fund

# 2. Compile TypeScript. Tests and vitest config are excluded by
#    tsconfig.build.json, so the image never contains them.
FROM deps AS build
COPY tsconfig.json tsconfig.build.json ./
COPY src ./src
RUN npm run build

# 3. Runtime: production dependencies only, non-root, no toolchain.
FROM node:22-alpine AS runtime
ENV NODE_ENV=production
WORKDIR /app

COPY package.json package-lock.json ./
RUN npm ci --omit=dev --no-audit --no-fund \
  && npm cache clean --force

COPY --from=build /app/dist ./dist

USER node
EXPOSE 3000

# Uses Node's own fetch, so the image needs no curl or wget.
HEALTHCHECK --interval=10s --timeout=3s --start-period=5s --retries=5 \
  CMD node -e "fetch('http://127.0.0.1:' + (process.env.PORT || 3000) + '/health').then((r) => process.exit(r.ok ? 0 : 1)).catch(() => process.exit(1))"

CMD ["node", "dist/main/server.js"]
```

```javascript
import js from "@eslint/js";
import globals from "globals";
import tseslint from "typescript-eslint";

/**
 * The Clean Architecture dependency rule, enforced rather than documented.
 * Inner layers may not import outer layers, frameworks, or SDKs.
 *
 * `main` is deliberately not restricted to "no domain imports": the
 * composition root is the outermost layer, and dependencies point inward, so
 * it is allowed to know every layer. What it must not do is host business
 * rules, which no import rule can express — `tests/architecture` and review
 * cover that.
 */
function forbidImports(patterns, message) {
  return {
    "no-restricted-imports": [
      "error",
      {
        patterns: [{ group: patterns, message }],
      },
    ],
  };
}

const frameworks = [
  "fastify",
  "zod",
  "mongodb",
  "ioredis",
  "kafkajs",
  "prom-client",
  "@prisma/client",
];

export default tseslint.config(
  { ignores: ["dist/", "coverage/", "node_modules/", "prisma/"] },
  js.configs.recommended,
  ...tseslint.configs.recommended,
  {
    files: ["**/*.ts"],
    languageOptions: {
      globals: globals.node,
    },
  },
  {
    files: ["src/domain/**/*.ts"],
    rules: forbidImports(
      [
        "**/application/**",
        "**/infrastructure/**",
        "**/main/**",
        ...frameworks,
        "node:*",
      ],
      "Domain must not depend on outer layers, frameworks, or the Node runtime.",
    ),
  },
  {
    files: ["src/application/**/*.ts"],
    rules: forbidImports(
      ["**/infrastructure/**", "**/main/**", ...frameworks, "node:*"],
      "Application must not depend on infrastructure, the composition root, frameworks, or the Node runtime; depend on a port instead.",
    ),
  },
  {
    files: ["src/infrastructure/**/*.ts"],
    rules: forbidImports(
      ["**/main/**"],
      "Adapters must not depend on the composition root that wires them.",
    ),
  },
);
```

`````markdown
# E-commerce Backend

An e-commerce backend that demonstrates Clean Architecture with **functional TypeScript**, plus the operational pieces a real service needs. It covers the full purchase path — customer, product, stock, cart, order, payment — with Fastify for HTTP, Zod at the edge, Vitest for tests, and no classes, no ORM, and no DI container.

Every external dependency sits behind a port with an in-process adapter, so the whole flow runs and is tested with no infrastructure. Real adapters are selected by configuration, without changing a single use case:

| Capability     | In-process default | Production adapter            |
| -------------- | ------------------ | ----------------------------- |
| Persistence    | shared maps        | MongoDB (transactions)        |
| Cache          | TTL map            | Redis                         |
| Idempotency    | TTL map + claims   | Redis `SET NX`                |
| Rate limiting  | fixed window       | Redis + Lua                   |
| Event delivery | stdout publisher   | Kafka producer (via outbox)   |
| Consumer       | —                  | Kafka, idempotent by event id |
| Metrics        | —                  | Prometheus `/metrics`         |

The second goal is the part most Clean Architecture examples skip: **runtime consistency**. Multi-write workflows have explicit transaction boundaries, events leave through a transactional outbox, checkout is idempotent with an atomic claim, and delivery is at-least-once with an idempotent consumer.

CUSTOMER=$(curl -s -X POST localhost:3000/customers \

The response contains a `paid` order and a `succeeded` payment, the cart is emptied, and the reserved stock is committed. `order.created` / `order.paid` are written to the outbox in the same transaction, delivered by the worker, and (when Kafka is configured) consumed by the order-events consumer.

## The dependency rule

| Layer            | May import                        | May **not** import                                            |
| ---------------- | --------------------------------- | ------------------------------------------------------------- |
| `domain`         | `domain`                          | `application`, `infrastructure`, `main`, frameworks, `node:*` |
| `application`    | `application`, `domain`           | `infrastructure`, `main`, frameworks, `node:*`                |
| `infrastructure` | `application`, `domain`, adapters | `main`                                                        |
| `main`           | anything inward                   | anything outside the graph; no business rules                 |

`tests/architecture/dependency-rules.test.ts` reads the sources and fails on a framework import in `domain`/`application` (Fastify, Zod, MongoDB, ioredis, KafkaJS, prom-client), an `infrastructure` → `main` import, or `process.env` / `Date.now` / `randomUUID` in the inner layers. The rules survive someone editing the ESLint config.

## Transactions

`application/ports/unit-of-work.ts`:

```ts
execute<T, E>(work: () => Promise<Result<T, E>>): Promise<Result<T, E | UnitOfWorkError>>;
```

The work returns a `Result`, and **a failure value rolls back**. Two adapters honour it: the in-memory snapshot (restore on failure, serialised queue) and MongoDB (snapshot reads, majority writes, abort on failure, retries on `TransientTransactionError` / `WriteConflict`). No use case changes when the adapter changes.

The MongoDB adapter propagates its session through an `AsyncLocalStorage`, so repositories join the transaction without the application threading a session argument through every port. The boundary stays explicit at the use case.

## Checkout, idempotency, and concurrency

```text
POST /checkout
      │
      ├─ key? ──► stored outcome? ──► replay (200, idempotent-replay: true)
      │      └──► acquire key ──► busy? ──► 409 checkout_in_progress
      │
      ▼
create-order ──► transaction { reserve stock, snapshot prices, clear cart, queue order.created }
      │
      ▼
process-payment ──► charge (outside the transaction, provider idempotency key)
      │
 success ────┤──── decline
   │                │
   ▼                ▼
commit stock     cancel-order ──► transaction { release stock, queue order.cancelled }
+ order.paid
```

- The key is scoped `checkout:<customerId>:<key>`, so customers cannot collide.
- Only successful outcomes are stored (24h). A decline is a real answer, so the claim is released and the caller may retry.
- The claim is atomic: the in-memory store checks and writes without yielding; Redis uses `SET NX EX`. Two simultaneous requests cannot both charge.
- If the store fails on lookup, checkout **fails closed** with `503 idempotency_unavailable`.
- A successful charge whose local commit fails returns `payment_requires_reconciliation` — surfaced, never silently retried.

## The outbox and Kafka

```text
transaction { state + outbox row } ──commit──► outbox worker
                                                   │
                                     dispatch primitive (at-least-once)
                                                   │
                                   EventPublisher ─┴─► stdout | Kafka producer
                                                   │
                                     mark published / record lastError + retry

Kafka topic (partitioned by order id) ──► consumer group (dedupes x-event-id)
```

- `OutboxMessage` carries a `DomainEvent`, an id, timestamps, `attempts`, `lastError` — no topic, header, group, or offset.
- `dispatch-outbox.ts` publishes one message at a time, records failures, and continues; the worker polls every `OUTBOX_POLL_INTERVAL_MS`.
- `infrastructure/kafka/kafka-messages.ts` owns the broker vocabulary: topic routing (`ecommerce.orders.v1`, `ecommerce.customers.v1`, catch-all), partition key (order id, then customer id), JSON body, and `x-event-id` / `x-event-name` / `x-event-version` headers.
- `kafka-topics.ts` creates missing topics at start-up, so a consumer never races auto-creation.
- The consumer subscribes to the order and customer topics and deduplicates by `x-event-id`, because delivery is at-least-once. Its seen-set is per-process and bounded; a real projection persists processed ids in the same transaction as the projection update.

## Redis

One connection, three adapters:

- **Cache** — `Cache` port used by `get-product`; JSON values with TTL. A miss or corrupt entry is just a miss.
- **Idempotency** — `SET NX EX` claim plus a TTL record; `save` writes the record and deletes the claim atomically in a `MULTI`.
- **Rate limiting** — `INCR` + `EXPIRE` inside a Lua script so a crash cannot leave a counter without a window.

The in-memory adapters remain the default, which is what lets the unit tests run without Docker; the Redis ones are covered by `tests/integration/redis`.

## Observability and operations

- **`GET /health`** — liveness: the process is up.
- **`GET /ready`** — readiness: pings MongoDB (`ping`), Redis (`PING`), Kafka (producer connect). Returns `503` with a per-dependency report when something is down.
- **`GET /metrics`** — Prometheus: `http_requests_total`, `http_request_duration_seconds` (route pattern, never raw URL), `checkout_total{outcome}`, `outbox_messages_total{result}`, plus Node defaults. Compose runs Prometheus to scrape it.
- **Request ids** — `x-request-id` is honoured when supplied and echoed on every response, so logs from different services join up.
- **Rate limiting** — a `preHandler` hook keyed by caller IP and route pattern; `x-ratelimit-*` headers on every response, `429` + `Retry-After` when exceeded. Exempt: `/health`, `/ready`, `/metrics`. Fails open if Redis is down (under-limiting beats a total outage).
- **Graceful shutdown** — on `SIGTERM`/`SIGINT`: stop the worker, close HTTP, then close adapters in reverse order.

## Known limitations

- **At-least-once delivery without a dead-letter queue.** Failed outbox rows retry every poll; a poison message would retry forever. `nextAttemptAt` + a DLQ after N attempts is the next step.
- **Consumer dedupe is per-process.** Restarting replays recent events to the handler; a real projection needs an inbox table written in the same transaction.
- **No reconciliation job.** `payment_requires_reconciliation` is surfaced and logged; nothing retries the commit or refunds the charge yet.
- **Payment is a stub.** `createInMemoryPaymentGateway` approves unless told to decline and remembers charges by idempotency key; a Stripe adapter implements the same port, with webhooks — not the request — confirming payment.
- **No auth.** There are no identity or authorization rules, so nothing could honestly be enforced.
- **No migrations.** Mongo collections and indexes are created at start-up; schema changes have no versioned migration yet.
- **Single-node MongoDB replica set and single Kafka broker.** Enough for correctness on one machine, not for production durability.
- **Metrics, not traces.** Prometheus counters and a scrape config exist; OpenTelemetry spans across HTTP → Mongo → outbox → Kafka do not.

### What to add next

1. **Stripe** — webhook confirmation, provider idempotency keys, refunds, reconciliation job.
2. **Outbox hardening** — backoff, `nextAttemptAt`, DLQ, and an inbox table for consumers.
3. **Auth** — JWT/cookie authentication at the HTTP boundary, authorization rules in the application.
4. **OpenTelemetry** — spans across HTTP, Mongo, outbox, Kafka, consumer; logs correlated by `x-request-id`.
5. **Grafana dashboard** — checkout outcomes, outbox lag, p99 latency, rate-limit rejections.
6. **Migrations + seed scripts** — versioned indexes/collections, deterministic demo data.
`````

```typescript
import {
  addItem as addItemToCart,
  createCart,
  type Cart,
} from "../../../domain/cart/cart.js";
import {
  checkAvailability,
  type InventoryItem,
} from "../../../domain/inventory/inventory-item.js";
import type { Product } from "../../../domain/product/product.js";
import { err, ok } from "../../../domain/shared/result.js";
import type { AddItem, AddItemDependencies } from "./add-item.types.js";

/**
 * Adding to a cart never touches stock: it only checks that the units could be
 * promised. Stock moves when an order is placed, which keeps carts disposable.
 */
export function addItemUseCase({
  carts,
  products,
  inventory,
  ids,
  clock,
}: AddItemDependencies): AddItem {
  return async (input) => {
    const now = clock.now();

    let product: Product | null;

    try {
      product = await products.findById(input.productId);
    } catch {
      return err({
        type: "repository_error",
        message: "Could not load product",
      });
    }

    if (product === null) {
      return err({
        type: "product_not_found",
        message: `Product ${input.productId} was not found`,
      });
    }

    let stock: InventoryItem | null;

    try {
      stock = await inventory.findByProductId(input.productId);
    } catch {
      return err({
        type: "repository_error",
        message: "Could not load stock",
      });
    }

    if (stock === null) {
      return err({
        type: "inventory_not_found",
        message: `No stock record exists for product ${input.productId}`,
      });
    }

    // A cart is a promise, not a reservation: this asks the inventory rule
    // whether the units could be promised and mutates nothing.
    const availability = checkAvailability(stock, input.quantity);

    if (!availability.ok) {
      return availability.error.type === "insufficient_stock"
        ? err({
            type: "insufficient_stock",
            message: availability.error.message,
          })
        : err({
            type: "invalid_cart_quantity",
            message: availability.error.message,
          });
    }

    let cart: Cart | null;

    try {
      cart = await carts.findByCustomerId(input.customerId);
    } catch {
      return err({
        type: "repository_error",
        message: "Could not load cart",
      });
    }

    const current =
      cart ??
      createCart({
        id: ids.nextId(),
        customerId: input.customerId,
        createdAt: now,
      });

    const updated = addItemToCart(current, {
      productId: product.id,
      quantity: input.quantity,
      unitPrice: product.price,
      addedAt: now,
    });

    if (!updated.ok) {
      return updated.error.type === "cart_currency_mismatch"
        ? err({
            type: "cart_currency_mismatch",
            message: updated.error.message,
          })
        : err({
            type: "invalid_cart_quantity",
            message: updated.error.message,
          });
    }

    try {
      await carts.save(updated.value);
    } catch {
      return err({
        type: "repository_error",
        message: "Could not save cart",
      });
    }

    return ok(updated.value);
  };
}
```

```typescript
import type {
  RemoveItem,
  RemoveItemDependencies,
} from "./remove-item.types.js";

export function removeItemUseCase({
  carts,
  clock,
}: RemoveItemDependencies): RemoveItem {
  return async (input) => {
    let cart: Cart | null;

    try {
      cart = await carts.findByCustomerId(input.customerId);
    } catch {
      return err({
        type: "repository_error",
        message: "Could not load cart",
      });
    }

    if (cart === null) {
      return err({
        type: "cart_not_found",
        message: `No cart exists for customer ${input.customerId}`,
      });
    }

    const updated = removeItemFromCart(cart, input.productId, clock.now());

    if (!updated.ok) {
      return err({
        type: "item_not_in_cart",
        message: updated.error.message,
      });
    }

    try {
      await carts.save(updated.value);
    } catch {
      return err({
        type: "repository_error",
        message: "Could not save cart",
      });
    }

    return ok(updated.value);
  };
}
```

```typescript
import { err, ok } from "../../domain/shared/result.js";
import type {
  Checkout,
  CheckoutDependencies,
  CheckoutOutcome,
  CheckoutResult,
} from "./checkout.types.js";

/** Long enough for a client retry window, short enough to stay disposable. */
const IDEMPOTENCY_TTL_SECONDS = 24 * 60 * 60;

/** A claim protects an in-flight request; it expires if the process dies. */
const IDEMPOTENCY_CLAIM_TTL_SECONDS = 30;

/**
 * Checkout is a composition, not a fifth copy of the same logic: place the
 * order, take the money, and cancel the order if the money never arrives.
 *
 * With an idempotency key it also refuses to do that twice. The key is scoped
 * to the customer, only successful outcomes are stored (a decline is a real
 * answer the caller may retry), and `acquire` closes the concurrency hole: two
 * simultaneous requests with the same new key cannot both start.
 */
export function checkoutUseCase({
  createOrder,
  processPayment,
  cancelOrder,
  idempotency,
  clock,
}: CheckoutDependencies): Checkout {
  return async (input) => {
    const key =
      input.idempotencyKey === undefined
        ? null
        : `checkout:${input.customerId}:${input.idempotencyKey}`;

    let claimed = false;

    if (key !== null) {
      try {
        const existing = await idempotency.find<CheckoutResult>(key);

        if (existing !== null) {
          return ok<CheckoutOutcome>({ ...existing.result, replayed: true });
        }

        const reservation = await idempotency.acquire(
          key,
          IDEMPOTENCY_CLAIM_TTL_SECONDS,
        );

        if (reservation === "busy") {
          return err({
            type: "checkout_in_progress",
            message:
              "A checkout with this idempotency key is already in progress",
          });
        }

        claimed = true;
      } catch {
        // Without a reliable store a retry could charge twice, so this request
        // fails closed rather than gambling with money.
        return err({
          type: "idempotency_unavailable",
          message: "Could not check the idempotency key",
        });
      }
    }

    try {
      const order = await createOrder({ customerId: input.customerId });

      if (!order.ok) {
        return err(order.error);
      }

      const payment = await processPayment({ orderId: order.value.id });

      if (!payment.ok) {
        // Compensating action: an unpaid order would otherwise hold stock
        // forever. The original failure is what the caller must see, even if
        // the compensation cannot be recorded.
        await cancelOrder({ orderId: order.value.id });

        return err(payment.error);
      }

      const outcome: CheckoutOutcome = {
        order: payment.value.order,
        payment: payment.value.payment,
        replayed: false,
      };

      if (key !== null) {
        try {
          await idempotency.save(
            key,
            {
              result: { order: outcome.order, payment: outcome.payment },
              createdAt: clock.now(),
            },
            IDEMPOTENCY_TTL_SECONDS,
          );
        } catch {
          // The money moved and the order exists; reporting a failure here
          // would invite a retry that creates a second order. The outcome is
          // returned as-is, and the missed replay protection is logged by the
          // adapter.
        }
      }

      return ok(outcome);
    } finally {
      if (claimed) {
        try {
          await idempotency.release(key as string);
        } catch {
          // The claim expires on its own; releasing is best effort.
        }
      }
    }
  };
}
```

```typescript
import {
  createCustomer,
  type Customer,
} from "../../../domain/customer/customer.js";
import { customerRegistered } from "../../../domain/customer/customer-events.js";
import { err, ok } from "../../../domain/shared/result.js";
import { stageEvent } from "../../outbox/stage-event.js";
import type {
  CreateCustomer,
  CreateCustomerDependencies,
  CreateCustomerError,
} from "./create-customer.types.js";

/**
 * Registration: validate through the domain, refuse a duplicate address, then
 * persist the customer and its `customer.registered` outbox row atomically.
 * Saving the customer without the event (or the reverse) is no longer possible.
 */
export function createCustomerUseCase({
  customers,
  ids,
  clock,
  outbox,
  unitOfWork,
}: CreateCustomerDependencies): CreateCustomer {
  return async (input) =>
    unitOfWork.execute<Customer, CreateCustomerError>(async () => {
      const now = clock.now();

      const customer = createCustomer({
        id: ids.nextId(),
        email: input.email,
        name: input.name,
        createdAt: now,
      });

      if (!customer.ok) {
        return err({
          type: "invalid_customer",
          message: customer.error.message,
        });
      }

      const existing = await customers.findByEmail(customer.value.email);

      if (existing !== null) {
        return err({
          type: "email_already_registered",
          message: "A customer with this email already exists",
        });
      }

      await customers.save(customer.value);
      await stageEvent(
        { outbox, ids, clock },
        customerRegistered(customer.value, now),
      );

      return ok(customer.value);
    });
}
```

```typescript
import {
  releaseStock,
  type InventoryItem,
} from "../../../domain/inventory/inventory-item.js";
import {
  cancelOrder as cancelOrderDomain,
  type Order,
} from "../../../domain/order/order.js";
import { orderCancelled } from "../../../domain/order/order-events.js";
import { err, ok } from "../../../domain/shared/result.js";
import { stageEvent } from "../../outbox/stage-event.js";
import type {
  CancelOrder,
  CancelOrderDependencies,
  CancelOrderError,
} from "./cancel-order.types.js";

/**
 * Cancelling is the inverse of placing, and it is one transaction: releasing
 * every reserved unit, marking the order cancelled, and recording
 * `order.cancelled` either all commit or none do.
 *
 * That matters most when checkout compensates for a declined payment: a
 * cancelled order whose stock was never released would leak inventory.
 */
export function cancelOrderUseCase({
  orders,
  inventory,
  ids,
  clock,
  outbox,
  unitOfWork,
}: CancelOrderDependencies): CancelOrder {
  return async ({ orderId }) =>
    unitOfWork.execute<Order, CancelOrderError>(async () => {
      const now = clock.now();

      const order = await orders.findById(orderId);

      if (order === null) {
        return err({
          type: "order_not_found",
          message: `Order ${orderId} was not found`,
        });
      }

      const cancelled = cancelOrderDomain(order, now);

      if (!cancelled.ok) {
        return err({
          type: cancelled.error.type,
          message: cancelled.error.message,
        });
      }

      const releases: InventoryItem[] = [];

      for (const item of order.items) {
        const stock: InventoryItem | null = await inventory.findByProductId(
          item.productId,
        );

        if (stock === null) {
          return err({
            type: "inventory_not_found",
            message: `No stock record exists for product ${item.productId}`,
          });
        }

        const released = releaseStock(stock, item.quantity, now);

        if (!released.ok) {
          // The order was payable, so its units must be reserved. Failing here
          // means storage and order history disagree; surface it, do not guess.
          return err({
            type: "repository_error",
            message: `Could not release reserved stock: ${released.error.message}`,
          });
        }

        releases.push(released.value);
      }

      for (const release of releases) {
        await inventory.save(release);
      }

      await orders.save(cancelled.value);
      await stageEvent(
        { outbox, ids, clock },
        orderCancelled(cancelled.value, now),
      );

      return ok(cancelled.value);
    });
}
```

```typescript
import { clearCart, type Cart } from "../../../domain/cart/cart.js";
import {
  reserveStock,
  type InventoryItem,
} from "../../../domain/inventory/inventory-item.js";
import { createOrder, type Order } from "../../../domain/order/order.js";
import { orderCreated } from "../../../domain/order/order-events.js";
import {
  orderItemFromCartItem,
  type OrderItem,
} from "../../../domain/order/order-item.js";
import { err, ok } from "../../../domain/shared/result.js";
import { stageEvent } from "../../outbox/stage-event.js";
import type {
  CreateOrder,
  CreateOrderDependencies,
  CreateOrderError,
} from "./create-order.types.js";

/**
 * Places an order inside one transaction: price snapshot, stock reservation,
 * the order itself, the emptied cart, and the `order.created` outbox row all
 * commit together or not at all.
 *
 * Nothing here publishes to a broker. If the write commits and the broker is
 * down, the outbox still holds the event, and the dispatcher retries it.
 */
export function createOrderUseCase({
  carts,
  orders,
  inventory,
  ids,
  clock,
  outbox,
  unitOfWork,
}: CreateOrderDependencies): CreateOrder {
  return async (input) =>
    unitOfWork.execute<Order, CreateOrderError>(async () => {
      const now = clock.now();

      const cart: Cart | null = await carts.findByCustomerId(input.customerId);

      if (cart === null) {
        return err({
          type: "cart_not_found",
          message: `No cart exists for customer ${input.customerId}`,
        });
      }

      if (cart.items.length === 0) {
        return err({
          type: "empty_cart",
          message: "Cart is empty",
        });
      }

      const items: OrderItem[] = [];

      for (const cartItem of cart.items) {
        const item = orderItemFromCartItem(cartItem);

        if (!item.ok) {
          return err({
            type: "invalid_order",
            message: item.error.message,
          });
        }

        items.push(item.value);
      }

      const order = createOrder({
        id: ids.nextId(),
        customerId: input.customerId,
        items,
        createdAt: now,
      });

      if (!order.ok) {
        return err({
          type: "invalid_order",
          message: order.error.message,
        });
      }

      const reservations: InventoryItem[] = [];

      for (const item of order.value.items) {
        const stock: InventoryItem | null = await inventory.findByProductId(
          item.productId,
        );

        if (stock === null) {
          return err({
            type: "inventory_not_found",
            message: `No stock record exists for product ${item.productId}`,
          });
        }

        const reserved = reserveStock(stock, item.quantity, now);

        if (!reserved.ok) {
          return err({
            type:
              reserved.error.type === "insufficient_stock"
                ? "insufficient_stock"
                : "invalid_order",
            message: reserved.error.message,
          });
        }

        reservations.push(reserved.value);
      }

      for (const reservation of reservations) {
        await inventory.save(reservation);
      }

      await orders.save(order.value);
      await carts.save(clearCart(cart, now));
      await stageEvent({ outbox, ids, clock }, orderCreated(order.value, now));

      return ok(order.value);
    });
}
```

```typescript
import { err, ok } from "../../domain/shared/result.js";
import type {
  DispatchOutbox,
  DispatchOutboxDependencies,
  OutboxDispatchSummary,
} from "./dispatch-outbox.types.js";

const DEFAULT_BATCH_SIZE = 50;

/**
 * The read side of the outbox: take pending messages, hand the broker-agnostic
 * event to the publisher, then mark the message delivered.
 *
 * The order matters. Marking before publishing would lose an event on a crash;
 * publishing twice after a crash is acceptable because consumers are expected
 * to be idempotent. That is the trade the outbox pattern makes.
 */
export function dispatchOutboxUseCase({
  outbox,
  publisher,
  clock,
  batchSize = DEFAULT_BATCH_SIZE,
}: DispatchOutboxDependencies): DispatchOutbox {
  return async () => {
    let pending;

    try {
      pending = await outbox.findPending(batchSize);
    } catch {
      return err({
        type: "outbox_unavailable",
        message: "Could not read pending outbox messages",
      });
    }

    const summary: OutboxDispatchSummary = { published: 0, failed: 0 };

    for (const message of pending) {
      try {
        await publisher.publish(message.event, { id: message.id });
        await outbox.markPublished(message.id, clock.now());
        summary.published += 1;
      } catch (error) {
        summary.failed += 1;

        try {
          await outbox.markFailed(
            message.id,
            error instanceof Error ? error.message : "Unknown delivery failure",
          );
        } catch {
          // The message stays pending, which is the safe state: it will be
          // picked up again on the next poll.
        }
      }
    }

    return ok(summary);
  };
}
```

```typescript
import {
  commitReservation,
  type InventoryItem,
} from "../../../domain/inventory/inventory-item.js";
import { payOrder, type Order } from "../../../domain/order/order.js";
import { orderPaid } from "../../../domain/order/order-events.js";
import {
  createPayment,
  failPayment,
  succeedPayment,
} from "../../../domain/payment/payment.js";
import { err, ok } from "../../../domain/shared/result.js";
import { stageEvent } from "../../outbox/stage-event.js";
import type { ChargeResult } from "../../ports/payment-gateway.js";
import type {
  ProcessPayment,
  ProcessPaymentDependencies,
  ProcessPaymentError,
} from "./process-payment.types.js";

/**
 * Payment crosses a distributed-system boundary, and this use case says so
 * instead of hiding it:
 *
 *   1. read and validate the order                  (no writes)
 *   2. charge the provider                          (external, not our data)
 *   3. commit stock, mark paid, stage order.paid     (one transaction)
 *
 * Step 2 is deliberately outside the transaction: a PostgreSQL rollback cannot
 * un-charge a card. The charge carries an idempotency key so a retry of step 2
 * returns the original provider reference instead of taking money twice.
 *
 * If step 3 fails after a successful charge, the caller gets
 * `payment_requires_reconciliation`: money moved but the order was not
 * recorded as paid. That is a real distributed-systems state, and it needs a
 * human or a reconciliation job, not a `try/catch`.
 */
export function processPaymentUseCase({
  orders,
  inventory,
  gateway,
  ids,
  clock,
  outbox,
  unitOfWork,
}: ProcessPaymentDependencies): ProcessPayment {
  return async ({ orderId }) => {
    const now = clock.now();

    const order: Order | null = await orders.findById(orderId);

    if (order === null) {
      return err({
        type: "order_not_found",
        message: `Order ${orderId} was not found`,
      });
    }

    const payable = payOrder(order, now);

    if (!payable.ok) {
      return err({
        type: payable.error.type,
        message: payable.error.message,
      });
    }

    const pending = createPayment({
      id: ids.nextId(),
      orderId: order.id,
      amount: order.total,
      createdAt: now,
    });

    if (!pending.ok) {
      return err({
        type: "invalid_payment",
        message: pending.error.message,
      });
    }

    let charge: ChargeResult;

    try {
      charge = await gateway.charge({
        orderId: order.id,
        customerId: order.customerId,
        amount: order.total,
        idempotencyKey: pending.value.id,
      });
    } catch {
      const failed = failPayment(
        pending.value,
        "Payment gateway did not respond",
        now,
      );

      return err({
        type: "payment_gateway_unavailable",
        message: "Payment gateway is unavailable",
        payment: failed.ok ? failed.value : pending.value,
      });
    }

    if (!charge.ok) {
      const failed = failPayment(pending.value, charge.error.message, now);
      const payment = failed.ok ? failed.value : pending.value;

      return charge.error.type === "payment_declined"
        ? err({
            type: "payment_declined",
            message: charge.error.message,
            payment,
          })
        : err({
            type: "payment_gateway_unavailable",
            message: charge.error.message,
            payment,
          });
    }

    const succeeded = succeedPayment(
      pending.value,
      charge.value.providerReference,
      now,
    );

    if (!succeeded.ok) {
      return err({
        type: "invalid_payment",
        message: succeeded.error.message,
      });
    }

    const recorded = await unitOfWork.execute<Order, ProcessPaymentError>(
      async () => {
        const current: Order | null = await orders.findById(orderId);

        if (current === null) {
          return err({
            type: "order_not_found" as const,
            message: `Order ${orderId} was not found`,
          });
        }

        const transition = payOrder(current, now);

        if (!transition.ok) {
          return err({
            type: transition.error.type,
            message: transition.error.message,
          });
        }

        // The charge succeeded, so held units become sold units.
        const commits: InventoryItem[] = [];

        for (const item of current.items) {
          const stock: InventoryItem | null = await inventory.findByProductId(
            item.productId,
          );

          if (stock === null) {
            return err({
              type: "inventory_not_found" as const,
              message: `No stock record exists for product ${item.productId}`,
            });
          }

          const committed = commitReservation(stock, item.quantity, now);

          if (!committed.ok) {
            return err({
              type: "repository_error" as const,
              message: `Could not commit reserved stock: ${committed.error.message}`,
            });
          }

          commits.push(committed.value);
        }

        for (const commit of commits) {
          await inventory.save(commit);
        }

        await orders.save(transition.value);
        await stageEvent(
          { outbox, ids, clock },
          orderPaid(transition.value, charge.value.providerReference, now),
        );

        return ok(transition.value);
      },
    );

    if (!recorded.ok) {
      return err({
        type: "payment_requires_reconciliation",
        message:
          "The payment was taken but the order could not be recorded as paid",
        payment: succeeded.value,
        cause: recorded.error.type,
      });
    }

    return ok({
      order: recorded.value,
      payment: succeeded.value,
    });
  };
}
```

```typescript
/**
 * The recorded outcome of an operation that already happened, keyed by the
 * caller's idempotency key. Replays return this instead of doing the work
 * again, so a retried checkout cannot create a second order.
 */
export type IdempotencyRecord<TResult> = {
  result: TResult;
  createdAt: string;
};

/**
 * `acquired` means this request owns the key and may do the work; `busy`
 * means another request is already doing it, so this one must not start.
 */
export type IdempotencyReservation = "acquired" | "busy";

/**
 * Short-lived storage for idempotent request outcomes. Redis implements this
 * in production with `SET NX` and a TTL; the in-memory adapter exists for tests
 * and local runs. The port knows nothing about either.
 *
 * `acquire` is the part that closes the double-charge race: two simultaneous
 * requests with the same unused key cannot both receive `acquired`.
 */
export type IdempotencyStore = {
  find<TResult>(key: string): Promise<IdempotencyRecord<TResult> | null>;
  save<TResult>(
    key: string,
    record: IdempotencyRecord<TResult>,
    ttlSeconds: number,
  ): Promise<void>;
  acquire(key: string, ttlSeconds: number): Promise<IdempotencyReservation>;
  /** Frees a claim that did not produce a stored outcome (a decline, a crash). */
  release(key: string): Promise<void>;
};
```

```typescript
import type { Result } from "../../domain/shared/result.js";

/**
 * The one failure infrastructure adds to a transaction: the boundary itself
 * could not be opened, committed, or rolled back. Business failures come from
 * the work, not from here.
 */
export type UnitOfWorkError = {
  type: "transaction_failed";
  message: string;
};

/**
 * "These changes commit together, or none of them do."
 *
 * The work returns a Result instead of throwing, which lets the port decide
 * from the *business* outcome whether to commit: a failure value rolls back.
 * Infrastructure implements this with a database transaction; the application
 * never learns whether that means PostgreSQL, an in-memory snapshot, or
 * anything else.
 */
export type UnitOfWork = {
  execute<T, E>(
    work: () => Promise<Result<T, E>>,
  ): Promise<Result<T, E | UnitOfWorkError>>;
};
```

```typescript
import { createInventoryItem } from "../../../domain/inventory/inventory-item.js";
import { createMoney } from "../../../domain/product/money.js";
import {
  createProduct,
  type Product,
} from "../../../domain/product/product.js";
import { err, ok } from "../../../domain/shared/result.js";
import type {
  CreateProduct,
  CreateProductDependencies,
  CreateProductError,
} from "./create-product.types.js";

/**
 * A product without stock cannot be sold, so creating one also opens its
 * inventory record. Splitting them would allow a product that no cart can fill,
 * which is why both rows go in one transaction.
 */
export function createProductUseCase({
  products,
  inventory,
  ids,
  clock,
  unitOfWork,
}: CreateProductDependencies): CreateProduct {
  return async (input) =>
    unitOfWork.execute<Product, CreateProductError>(async () => {
      const now = clock.now();

      const price = createMoney(input.amountInMinorUnits, input.currency);

      if (!price.ok) {
        return err({
          type: "invalid_product",
          message: price.error.message,
        });
      }

      const product = createProduct({
        id: ids.nextId(),
        name: input.name,
        price: price.value,
        createdAt: now,
      });

      if (!product.ok) {
        return err({
          type: "invalid_product",
          message: product.error.message,
        });
      }

      const stock = createInventoryItem({
        id: ids.nextId(),
        productId: product.value.id,
        quantity: input.availableQuantity ?? 0,
        updatedAt: now,
      });

      if (!stock.ok) {
        return err({
          type: "invalid_inventory",
          message: stock.error.message,
        });
      }

      await products.save(product.value);
      await inventory.save(stock.value);

      return ok(product.value);
    });
}
```

```typescript
import type { Product } from "../../../domain/product/product.js";
import { err, ok } from "../../../domain/shared/result.js";
import type {
  GetProduct,
  GetProductDependencies,
} from "./get-product.types.js";

export const PRODUCT_CACHE_TTL_SECONDS = 60;

const cacheKey = (id: string): string => `product:${id}`;

/**
 * Read-through: a hit shortens the path, a miss falls back to the repository,
 * and a cache failure is ignored. The cache can only ever make this slower, so
 * its errors are not treated as request failures.
 */
export function getProductUseCase({
  products,
  cache,
}: GetProductDependencies): GetProduct {
  return async ({ id }) => {
    try {
      const cached = await cache.get<Product>(cacheKey(id));

      if (cached !== null) {
        return ok(cached);
      }
    } catch {
      // Cache is an optimisation, not a source of truth.
    }

    let product: Product | null;

    try {
      product = await products.findById(id);
    } catch {
      return err({
        type: "repository_error",
        message: "Could not load product",
      });
    }

    if (product === null) {
      return err({
        type: "product_not_found",
        message: `Product ${id} was not found`,
      });
    }

    try {
      await cache.set(cacheKey(id), product, PRODUCT_CACHE_TTL_SECONDS);
    } catch {
      // Losing a cache write costs a future repository read, nothing more.
    }

    return ok(product);
  };
}
```

```typescript
import type { Money } from "../product/money.js";
import type { ProductId } from "../product/product-id.js";
import { err, ok, type Result } from "../shared/result.js";
import type { CartDomainError } from "./cart-errors.js";

export const MAX_ITEM_QUANTITY = 99;

/**
 * A cart line remembers the price it was added at, so a price change does not
 * silently rewrite what the customer saw.
 */
export type CartItem = {
  productId: ProductId;
  quantity: number;
  unitPrice: Money;
};

export function createCartItem(input: {
  productId: ProductId;
  quantity: number;
  unitPrice: Money;
}): Result<CartItem, CartDomainError> {
  if (
    !Number.isInteger(input.quantity) ||
    input.quantity < 1 ||
    input.quantity > MAX_ITEM_QUANTITY
  ) {
    return err({
      type: "invalid_cart_quantity",
      message: `Quantity must be a whole number between 1 and ${MAX_ITEM_QUANTITY}`,
    });
  }

  return ok({
    productId: input.productId,
    quantity: input.quantity,
    unitPrice: input.unitPrice,
  });
}

export function cartItemTotal(item: CartItem): Money {
  return {
    amountInMinorUnits: item.unitPrice.amountInMinorUnits * item.quantity,
    currency: item.unitPrice.currency,
  };
}
```

```typescript
import type { CustomerId } from "../customer/customer-id.js";
import type { Money } from "../product/money.js";
import type { ProductId } from "../product/product-id.js";
import { ok, type Result } from "../shared/result.js";
import {
  cartItemTotal,
  createCartItem,
  MAX_ITEM_QUANTITY,
  type CartItem,
} from "./cart-item.js";
import type { CartDomainError } from "./cart-errors.js";

export type CartId = string;

/** One open cart per customer, holding priced lines and nothing else. */
export type Cart = {
  id: CartId;
  customerId: CustomerId;
  items: CartItem[];
  createdAt: string;
  updatedAt: string;
};

export function createCart(input: {
  id: CartId;
  customerId: CustomerId;
  createdAt: string;
}): Cart {
  return {
    id: input.id,
    customerId: input.customerId,
    items: [],
    createdAt: input.createdAt,
    updatedAt: input.createdAt,
  };
}

/**
 * Adds a line, merging into an existing line for the same product. All lines
 * must share one currency, otherwise the cart total would be undefined.
 */
export function addItem(
  cart: Cart,
  input: {
    productId: ProductId;
    quantity: number;
    unitPrice: Money;
    addedAt: string;
  },
): Result<Cart, CartDomainError> {
  const candidate = createCartItem({
    productId: input.productId,
    quantity: input.quantity,
    unitPrice: input.unitPrice,
  });

  if (!candidate.ok) {
    return candidate;
  }

  const cartCurrency = cart.items[0]?.unitPrice.currency;

  if (cartCurrency !== undefined && cartCurrency !== input.unitPrice.currency) {
    return {
      ok: false,
      error: {
        type: "cart_currency_mismatch",
        message: `This cart is priced in ${cartCurrency}`,
      },
    };
  }

  const existing = cart.items.find(
    (item) => item.productId === input.productId,
  );

  if (existing === undefined) {
    return ok({
      ...cart,
      items: [...cart.items, candidate.value],
      updatedAt: input.addedAt,
    });
  }

  const quantity = existing.quantity + candidate.value.quantity;

  if (quantity > MAX_ITEM_QUANTITY) {
    return {
      ok: false,
      error: {
        type: "invalid_cart_quantity",
        message: `A cart line cannot exceed ${MAX_ITEM_QUANTITY} units`,
      },
    };
  }

  return ok({
    ...cart,
    items: cart.items.map((item) =>
      item.productId === input.productId
        ? { ...item, quantity, unitPrice: input.unitPrice }
        : item,
    ),
    updatedAt: input.addedAt,
  });
}

export function removeItem(
  cart: Cart,
  productId: ProductId,
  removedAt: string,
): Result<Cart, CartDomainError> {
  const exists = cart.items.some((item) => item.productId === productId);

  if (!exists) {
    return {
      ok: false,
      error: {
        type: "item_not_in_cart",
        message: `Product ${productId} is not in this cart`,
      },
    };
  }

  return ok({
    ...cart,
    items: cart.items.filter((item) => item.productId !== productId),
    updatedAt: removedAt,
  });
}

export function clearCart(cart: Cart, clearedAt: string): Cart {
  return { ...cart, items: [], updatedAt: clearedAt };
}

/** Total of a cart, or `null` when it is empty (so no currency is implied). */
export function cartTotal(cart: Cart): Money | null {
  const first = cart.items[0];

  if (first === undefined) {
    return null;
  }

  return cart.items.reduce<Money>(
    (total, item) => ({
      amountInMinorUnits:
        total.amountInMinorUnits + cartItemTotal(item).amountInMinorUnits,
      currency: total.currency,
    }),
    { amountInMinorUnits: 0, currency: first.unitPrice.currency },
  );
}

export function cartItemCount(cart: Cart): number {
  return cart.items.reduce((count, item) => count + item.quantity, 0);
}
```

```typescript
import { err, ok, type Result } from "../shared/result.js";
import type { CustomerDomainError } from "./customer-errors.js";
import type { CustomerId } from "./customer-id.js";

export const MAX_CUSTOMER_NAME_LENGTH = 120;

/**
 * Deliberately permissive: the goal is to reject obvious garbage, not to
 * reimplement RFC 5322. Verification belongs to a later flow.
 */
const EMAIL_PATTERN = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;

export type Customer = {
  id: CustomerId;
  email: string;
  name: string;
  createdAt: string;
};

/**
 * Registers a customer. Emails are normalised so the same address cannot be
 * registered twice with different casing, and the id/clock stay injected.
 */
export function createCustomer(input: {
  id: CustomerId;
  email: string;
  name: string;
  createdAt: string;
}): Result<Customer, CustomerDomainError> {
  const email = input.email.trim().toLowerCase();
  const name = input.name.trim();

  if (!EMAIL_PATTERN.test(email)) {
    return err({
      type: "invalid_email",
      message: "Customer email is not a valid address",
    });
  }

  if (name.length === 0) {
    return err({
      type: "invalid_customer_name",
      message: "Customer name cannot be empty",
    });
  }

  if (name.length > MAX_CUSTOMER_NAME_LENGTH) {
    return err({
      type: "invalid_customer_name",
      message: `Customer name cannot exceed ${MAX_CUSTOMER_NAME_LENGTH} characters`,
    });
  }

  return ok({
    id: input.id,
    email,
    name,
    createdAt: input.createdAt,
  });
}

/** Renames a customer, keeping identity and registration date intact. */
export function renameCustomer(
  customer: Customer,
  name: string,
): Result<Customer, CustomerDomainError> {
  const trimmed = name.trim();

  if (trimmed.length === 0) {
    return err({
      type: "invalid_customer_name",
      message: "Customer name cannot be empty",
    });
  }

  if (trimmed.length > MAX_CUSTOMER_NAME_LENGTH) {
    return err({
      type: "invalid_customer_name",
      message: `Customer name cannot exceed ${MAX_CUSTOMER_NAME_LENGTH} characters`,
    });
  }

  return ok({ ...customer, name: trimmed });
}
```

```typescript
import type { ProductId } from "../product/product-id.js";
import { err, ok, type Result } from "../shared/result.js";
import type { InventoryDomainError } from "./inventory-errors.js";
import type { InventoryId } from "./inventory-id.js";

/**
 * Stock is split into what is free to promise (`available`) and what is held
 * for an open order (`reserved`). The split is what makes a reservation
 * reversible without losing the fact that units exist.
 */
export type InventoryItem = {
  id: InventoryId;
  productId: ProductId;
  available: number;
  reserved: number;
  updatedAt: string;
};

function isValidQuantity(quantity: number, minimum: number): boolean {
  return Number.isInteger(quantity) && quantity >= minimum;
}

export function createInventoryItem(input: {
  id: InventoryId;
  productId: ProductId;
  quantity: number;
  updatedAt: string;
}): Result<InventoryItem, InventoryDomainError> {
  if (!isValidQuantity(input.quantity, 0)) {
    return err({
      type: "invalid_quantity",
      message: "Initial quantity must be a non-negative integer",
    });
  }

  return ok({
    id: input.id,
    productId: input.productId,
    available: input.quantity,
    reserved: 0,
    updatedAt: input.updatedAt,
  });
}

/**
 * Answers "could these units be promised?" without changing anything.
 *
 * A check and a reservation are different operations: reading stock to price a
 * cart is not a mutation, so it must not look like one. `reserveStock` uses
 * this function, which keeps the definition of "enough" in exactly one place.
 */
export function checkAvailability(
  item: InventoryItem,
  quantity: number,
): Result<true, InventoryDomainError> {
  if (!isValidQuantity(quantity, 1)) {
    return err({
      type: "invalid_quantity",
      message: "Requested quantity must be a positive integer",
    });
  }

  if (item.available < quantity) {
    return err({
      type: "insufficient_stock",
      message: `Only ${item.available} unit(s) of product ${item.productId} are available`,
    });
  }

  return ok(true);
}

/** Holds units for an order. Fails when not enough stock is free. */
export function reserveStock(
  item: InventoryItem,
  quantity: number,
  reservedAt: string,
): Result<InventoryItem, InventoryDomainError> {
  const availability = checkAvailability(item, quantity);

  if (!availability.ok) {
    return err({
      type: availability.error.type,
      message: availability.error.message.replace(
        "Requested quantity",
        "Reserved quantity",
      ),
    });
  }

  return ok({
    ...item,
    available: item.available - quantity,
    reserved: item.reserved + quantity,
    updatedAt: reservedAt,
  });
}

/** Returns held units to the free pool, used when an order is cancelled. */
export function releaseStock(
  item: InventoryItem,
  quantity: number,
  releasedAt: string,
): Result<InventoryItem, InventoryDomainError> {
  if (!isValidQuantity(quantity, 1)) {
    return err({
      type: "invalid_quantity",
      message: "Released quantity must be a positive integer",
    });
  }

  if (item.reserved < quantity) {
    return err({
      type: "invalid_quantity",
      message: "Cannot release more units than are reserved",
    });
  }

  return ok({
    ...item,
    available: item.available + quantity,
    reserved: item.reserved - quantity,
    updatedAt: releasedAt,
  });
}

/** Consumes held units for good, used once payment has succeeded. */
export function commitReservation(
  item: InventoryItem,
  quantity: number,
  committedAt: string,
): Result<InventoryItem, InventoryDomainError> {
  if (!isValidQuantity(quantity, 1)) {
    return err({
      type: "invalid_quantity",
      message: "Committed quantity must be a positive integer",
    });
  }

  if (item.reserved < quantity) {
    return err({
      type: "invalid_quantity",
      message: "Cannot commit more units than are reserved",
    });
  }

  return ok({
    ...item,
    reserved: item.reserved - quantity,
    updatedAt: committedAt,
  });
}

/** Adds newly delivered units to the free pool. */
export function restock(
  item: InventoryItem,
  quantity: number,
  restockedAt: string,
): Result<InventoryItem, InventoryDomainError> {
  if (!isValidQuantity(quantity, 1)) {
    return err({
      type: "invalid_quantity",
      message: "Restocked quantity must be a positive integer",
    });
  }

  return ok({
    ...item,
    available: item.available + quantity,
    updatedAt: restockedAt,
  });
}
```

```typescript
import type { CustomerId } from "../customer/customer-id.js";
import { addMoney, type Money } from "../product/money.js";
import { err, ok, type Result } from "../shared/result.js";
import type { OrderDomainError, OrderTransitionError } from "./order-errors.js";
import type { OrderItem } from "./order-item.js";
import type { OrderStatus } from "./order-status.js";

export type OrderId = string;

export type Order = {
  id: OrderId;
  customerId: CustomerId;
  items: OrderItem[];
  total: Money;
  status: OrderStatus;
  createdAt: string;
  updatedAt: string;
  paidAt: string | null;
  cancelledAt: string | null;
};

/**
 * The total is always derived from the lines. Accepting a total from the
 * caller would allow an order whose price does not match its contents.
 */
function sumOrderItems(items: OrderItem[]): Result<Money, OrderDomainError> {
  const first = items[0];

  if (first === undefined) {
    return err({
      type: "empty_order",
      message: "An order must contain at least one item",
    });
  }

  let total: Money = {
    amountInMinorUnits: 0,
    currency: first.unitPrice.currency,
  };

  for (const item of items) {
    const sum = addMoney(total, item.lineTotal);

    if (!sum.ok) {
      return err({
        type: "invalid_order_item",
        message: sum.error.message,
      });
    }

    total = sum.value;
  }

  return ok(total);
}

export function createOrder(input: {
  id: OrderId;
  customerId: CustomerId;
  items: OrderItem[];
  createdAt: string;
}): Result<Order, OrderDomainError> {
  const total = sumOrderItems(input.items);

  if (!total.ok) {
    return total;
  }

  return ok({
    id: input.id,
    customerId: input.customerId,
    items: input.items,
    total: total.value,
    status: "pending_payment",
    createdAt: input.createdAt,
    updatedAt: input.createdAt,
    paidAt: null,
    cancelledAt: null,
  });
}

export function payOrder(
  order: Order,
  paidAt: string,
): Result<Order, OrderTransitionError> {
  if (order.status === "paid") {
    return err({
      type: "order_already_paid",
      message: "Order has already been paid",
    });
  }

  if (order.status === "cancelled") {
    return err({
      type: "order_cancelled",
      message: "A cancelled order cannot be paid",
    });
  }

  return ok({
    ...order,
    status: "paid",
    paidAt,
    updatedAt: paidAt,
  });
}

export function cancelOrder(
  order: Order,
  cancelledAt: string,
): Result<Order, OrderTransitionError> {
  if (order.status === "paid") {
    return err({
      type: "order_already_paid",
      message: "A paid order cannot be cancelled",
    });
  }

  if (order.status === "cancelled") {
    return err({
      type: "order_cancelled",
      message: "Order has already been cancelled",
    });
  }

  return ok({
    ...order,
    status: "cancelled",
    cancelledAt,
    updatedAt: cancelledAt,
  });
}
```

```typescript
export type PaymentId = string;

export type Payment = {
  id: PaymentId;
  orderId: OrderId;
  amount: Money;
  status: PaymentStatus;
  providerReference: string | null;
  failureReason: string | null;
  createdAt: string;
  updatedAt: string;

export function createPayment(input: {
  id: PaymentId;
  orderId: OrderId;
  amount: Money;
  createdAt: string;
}): Result<Payment, PaymentDomainError> {
  if (input.amount.amountInMinorUnits <= 0) {
    return err({
      type: "invalid_payment_amount",
      message: "A payment amount must be greater than zero",
    });
  }

  return ok({
    id: input.id,
    orderId: input.orderId,
    amount: input.amount,
    status: "pending",
    providerReference: null,
    failureReason: null,
    createdAt: input.createdAt,
    updatedAt: input.createdAt,
  });
}

export function succeedPayment(
  payment: Payment,
  providerReference: string,
  succeededAt: string,
): Result<Payment, PaymentDomainError> {
  if (payment.status !== "pending") {
    return err({
      type: "payment_already_resolved",
      message: `Payment is already ${payment.status}`,
    });
  }

  return ok({
    ...payment,
    status: "succeeded",
    providerReference,
    updatedAt: succeededAt,
  });
}

export function failPayment(
  payment: Payment,
  failureReason: string,
  failedAt: string,
): Result<Payment, PaymentDomainError> {
  if (payment.status !== "pending") {
    return err({
      type: "payment_already_resolved",
      message: `Payment is already ${payment.status}`,
    });
  }

  return ok({
    ...payment,
    status: "failed",
    failureReason,
    updatedAt: failedAt,
  });
}
```

```typescript
import { err, ok, type Result } from "../shared/result.js";
import type { ProductDomainError } from "./product-errors.js";

/**
 * Money as integer minor units plus a currency code. Floats are never used for
 * prices: 19.99 is stored as 1999, so totals cannot drift.
 */
export type Money = {
  amountInMinorUnits: number;
  currency: string;
};

const CURRENCY_PATTERN = /^[A-Z]{3}$/;

export function createMoney(
  amountInMinorUnits: number,
  currency: string,
): Result<Money, ProductDomainError> {
  const normalizedCurrency = currency.trim().toUpperCase();

  if (!Number.isSafeInteger(amountInMinorUnits) || amountInMinorUnits < 0) {
    return err({
      type: "invalid_amount",
      message: "Amount must be a non-negative integer in minor units",
    });
  }

  if (!CURRENCY_PATTERN.test(normalizedCurrency)) {
    return err({
      type: "invalid_currency",
      message: "Currency must be a three-letter ISO code",
    });
  }

  return ok({
    amountInMinorUnits,
    currency: normalizedCurrency,
  });
}

/** Adds two amounts, refusing to mix currencies silently. */
export function addMoney(
  left: Money,
  right: Money,
): Result<Money, ProductDomainError> {
  if (left.currency !== right.currency) {
    return err({
      type: "currency_mismatch",
      message: `Cannot combine ${left.currency} with ${right.currency}`,
    });
  }

  return createMoney(
    left.amountInMinorUnits + right.amountInMinorUnits,
    left.currency,
  );
}

/** Multiplies an amount by a whole quantity; the caller has bounded quantity. */
export function multiplyMoney(money: Money, quantity: number): Money {
  return {
    amountInMinorUnits: money.amountInMinorUnits * quantity,
    currency: money.currency,
  };
}

export function formatMoney(money: Money): string {
  return `${(money.amountInMinorUnits / 100).toFixed(2)} ${money.currency}`;
}
```

```typescript
import type { Cache } from "../../application/ports/cache.js";

type Entry = {
  value: unknown;
  expiresAt: number;
};

/**
 * A disposable cache. The clock is injectable so expiry is testable without
 * waiting, and entries are removed on read once they are stale.
 */
export function createInMemoryCache(now: () => number = Date.now): Cache {
  const entries = new Map<string, Entry>();

  return {
    async get<T>(key: string): Promise<T | null> {
      const entry = entries.get(key);

      if (entry === undefined) {
        return null;
      }

      if (entry.expiresAt <= now()) {
        entries.delete(key);
        return null;
      }

      return entry.value as T;
    },

    async set<T>(key: string, value: T, ttlSeconds: number): Promise<void> {
      entries.set(key, {
        value,
        expiresAt: now() + ttlSeconds * 1000,
      });
    },

    async delete(key: string): Promise<void> {
      entries.delete(key);
    },
  };
}
```

```typescript
/** Loads a local `.env` when present, then hands back `process.env`. */
export function loadEnvironment(): NodeJS.ProcessEnv {
  if (existsSync(".env")) {
    process.loadEnvFile();
  }

  return process.env;

function parseBrokers(value: string | undefined): string[] | null {
  if (value === undefined) {
    return null;
  }

  const brokers = value
    .split(",")
    .map((broker) => broker.trim())
    .filter((broker) => broker.length > 0);

  return brokers.length === 0 ? null : brokers;
}

/**
 * Validates the environment once, at the edge. No other module reads
 * `process.env`, so defaults and failure messages cannot drift apart.
 */
export function parseEnvironment(
  env: NodeJS.ProcessEnv,
): Result<Config, ConfigError> {
  const parsed = envSchema.safeParse(env);

  if (!parsed.success) {
    const details = parsed.error.issues
      .map(
        (issue) => `${issue.path.join(".") || "environment"}: ${issue.message}`,
      )
      .join("; ");

    return err({
      type: "invalid_configuration",
      message: `Invalid configuration: ${details}`,
    });
  }

  return ok({
    port: parsed.data.PORT,
    nodeEnv: parsed.data.NODE_ENV,
    mongodbUri: parsed.data.MONGODB_URI ?? null,
    mongodbDatabase: parsed.data.MONGODB_DATABASE,
    redisUrl: parsed.data.REDIS_URL ?? null,
    kafkaBrokers: parseBrokers(parsed.data.KAFKA_BROKERS),
    kafkaClientId: parsed.data.KAFKA_CLIENT_ID,
    kafkaConsumerGroup: parsed.data.KAFKA_CONSUMER_GROUP,
    rateLimit: {
      max: parsed.data.RATE_LIMIT_MAX,
      windowSeconds: parsed.data.RATE_LIMIT_WINDOW_SECONDS,
    },
    outboxPollIntervalMs: parsed.data.OUTBOX_POLL_INTERVAL_MS,
  });
}
```

```typescript
/**
 * A dependency the process needs in order to serve traffic. Liveness answers
 * "is this process alive"; readiness answers "should a load balancer send it
 * work", which is why it pings the database and the cache.
 */
export type HealthCheck = {
  name: string;
  check(): Promise<void>;
};

export type HealthReport = {
  status: "ok" | "degraded";
  checks: Record<string, "up" | "down">;
};

export async function runHealthChecks(
  checks: HealthCheck[],
): Promise<HealthReport> {
  const results = await Promise.allSettled(
    checks.map(async (check) => {
      await check.check();
      return check.name;
    }),
  );

  const report: Record<string, "up" | "down"> = {};

  results.forEach((result, index) => {
    const name = checks[index]?.name ?? "unknown";
    report[name] = result.status === "fulfilled" ? "up" : "down";
  });

  const healthy = Object.values(report).every((status) => status === "up");

  return {
    status: healthy ? "ok" : "degraded",
    checks: report,
  };
}
```

```typescript
import type { FastifyReply, FastifyRequest } from "fastify";
import type { Checkout } from "../../../application/checkout/checkout.types.js";
import { sendApplicationError } from "../http-errors.js";
import { toCheckoutResponse } from "../presenters/checkout-presenter.js";
import { checkoutBodySchema } from "../schemas/order-schemas.js";

type CheckoutControllerDependencies = {
  checkout: Checkout;
};

const MAX_IDEMPOTENCY_KEY_LENGTH = 200;

/**
 * Reads the caller's idempotency key. A malformed header is a client error;
 * an absent one simply means "no replay protection for this request".
 */
function readIdempotencyKey(
  request: FastifyRequest,
): { ok: true; key: string | undefined } | { ok: false } {
  const header = request.headers["idempotency-key"];

  if (header === undefined) {
    return { ok: true, key: undefined };
  }

  if (typeof header !== "string") {
    return { ok: false };
  }

  const key = header.trim();

  if (key.length === 0 || key.length > MAX_IDEMPOTENCY_KEY_LENGTH) {
    return { ok: false };
  }

  return { ok: true, key };
}

export function createCheckoutController({
  checkout,
}: CheckoutControllerDependencies) {
  return {
    async checkout(
      request: FastifyRequest,
      reply: FastifyReply,
    ): Promise<void> {
      const body = checkoutBodySchema.safeParse(request.body);
      const idempotencyKey = readIdempotencyKey(request);

      if (!body.success || !idempotencyKey.ok) {
        reply.code(400).send({ message: "Invalid request" });
        return;
      }

      const result = await checkout(
        idempotencyKey.key === undefined
          ? { customerId: body.data.customerId }
          : {
              customerId: body.data.customerId,
              idempotencyKey: idempotencyKey.key,
            },
      );

      if (!result.ok) {
        sendApplicationError(reply, result.error);
        return;
      }

      if (result.value.replayed) {
        reply.header("idempotent-replay", "true");
      }

      reply
        .code(result.value.replayed ? 200 : 201)
        .send(toCheckoutResponse(result.value));
    },
  };
}

export type CheckoutController = ReturnType<typeof createCheckoutController>;
```

```typescript
import type { CheckoutController } from "./controllers/checkout-controller.js";
import type { CustomerController } from "./controllers/customer-controller.js";
import type { OrderController } from "./controllers/order-controller.js";
import type { ProductController } from "./controllers/product-controller.js";
import { registerHealthRoutes } from "./health-routes.js";
import { registerRateLimit } from "./rate-limit.js";
import { registerCartRoutes } from "./routes/cart-routes.js";
import { registerCheckoutRoutes } from "./routes/checkout-routes.js";
import { registerCustomerRoutes } from "./routes/customer-routes.js";
import { registerOrderRoutes } from "./routes/order-routes.js";
import { registerProductRoutes } from "./routes/product-routes.js";

export type HttpControllers = {
  customers: CustomerController;
  products: ProductController;
  carts: CartController;
  orders: OrderController;
  checkout: CheckoutController;
};

type HttpAppOptions = {
  controllers: HttpControllers;
  logger?: boolean;
  /** Omitted in tests that do not care about limiting. */
  rateLimiter?: RateLimiter;
  metrics?: Metrics;
  healthChecks?: HealthCheck[];
};

/**
 * Builds the HTTP adapter. It never listens, so tests can drive the real
 * routes and error handler through `inject` without a socket.
 *
 * Request ids are honoured from `x-request-id` when the caller supplies one,
 * which is what makes logs and traces joinable across services.
 */
export function buildHttpApp({
  controllers,
  logger = true,
  rateLimiter,
  metrics,
  healthChecks = [],
}: HttpAppOptions): FastifyInstance {
  const app = Fastify({
    logger,
    genReqId: (request) => {
      const incoming = request.headers["x-request-id"];

      return typeof incoming === "string" &&
        incoming.length > 0 &&
        incoming.length <= 128
        ? incoming
        : randomUUID();
    },
  });

  if (metrics !== undefined) {
    app.addHook("onResponse", async (request, reply) => {
      const route =
        (request as { routeOptions?: { url?: string } }).routeOptions?.url ??
        request.url;

      metrics.observeHttpRequest({
        method: request.method,
        route,
        statusCode: reply.statusCode,
        durationSeconds: reply.elapsedTime / 1000,
      });
    });
  }

  app.addHook("onSend", async (request, reply, payload) => {
    reply.header("x-request-id", request.id);
    return payload;
  });

  registerHealthRoutes(app, {
    checks: healthChecks,
    ...(metrics === undefined ? {} : { metrics }),
  });

  registerCustomerRoutes(app, controllers.customers);
  registerProductRoutes(app, controllers.products);
  registerCartRoutes(app, controllers.carts);
  registerOrderRoutes(app, controllers.orders);
  registerCheckoutRoutes(app, controllers.checkout);

  if (rateLimiter !== undefined) {
    registerRateLimit(app, rateLimiter);
  }

  // Unexpected failures are logged once, here, and answered without detail.
  app.setErrorHandler((error, request, reply) => {
    const fastifyError = error as FastifyError;
    const statusCode = fastifyError.statusCode ?? 500;

    if (statusCode >= 500) {
      request.log.error({ err: fastifyError }, "Unhandled request error");
      return reply.code(500).send({ message: "Internal server error" });
    }

    return reply.code(statusCode).send({ message: fastifyError.message });
  });

  return app;
}
```

```typescript
  invalid_product: 400,
  invalid_inventory: 400,
  invalid_order: 400,
  invalid_payment: 400,
  invalid_cart_quantity: 400,

  order_already_paid: 409,
  order_cancelled: 409,
  empty_cart: 409,
  item_not_in_cart: 409,
  payment_declined: 402,
  payment_gateway_unavailable: 502,
  idempotency_unavailable: 503,
  checkout_in_progress: 409,
};

export function statusForError(errorType: string): number {
  if (errorType.endsWith("_not_found")) {
    return 404;
  }

  if (errorType.startsWith("invalid_")) {
    return 400;
  }

  return EXPLICIT_STATUSES[errorType] ?? 500;
}

 * or broker details never reach a client.
 */

  reply: FastifyReply,
  error: { type: string; message: string },
): void {
  const status = statusForError(error.type);

  if (status >= 500) {
    reply.code(status).send({ message: "Internal server error" });
    return;
  }

  reply.code(status).send({ message: error.message });
}
```

```typescript
import type { FastifyInstance } from "fastify";
import type { RateLimiter } from "../../application/ports/rate-limiter.js";

const EXEMPT_PATHS = new Set(["/health", "/ready", "/metrics"]);

/**
 * A preHandler hook, not a business rule: it runs before validation and never
 * touches a use case. The limiter itself is a port, so this works the same
 * with Redis (shared across instances) or the in-memory fallback.
 *
 * If the limiter fails (Redis outage) the request is allowed through: refusing
 * all traffic because the counter store is down is worse than under-limiting.
 */
export function registerRateLimit(
  app: FastifyInstance,
  limiter: RateLimiter,
): void {
  app.addHook("preHandler", async (request, reply) => {
    const path = request.url.split("?")[0] ?? request.url;

    if (EXEMPT_PATHS.has(path)) {
      return;
    }

    const route =
      (request as { routeOptions?: { url?: string } }).routeOptions?.url ??
      path;

    try {
      const decision = await limiter.consume(`${request.ip}:${route}`);

      reply
        .header("x-ratelimit-limit", decision.limit)
        .header("x-ratelimit-remaining", decision.remaining)
        .header("x-ratelimit-reset", decision.resetInSeconds);

      if (!decision.allowed) {
        request.log.warn({ route, ip: request.ip }, "Rate limit exceeded");

        return reply
          .header("retry-after", decision.resetInSeconds)
          .code(429)
          .send({ message: "Too many requests" });
      }
    } catch (error) {
      request.log.error({ err: error }, "Rate limiter unavailable; allowing");
    }
  });
}
```

```typescript
import type {
  IdempotencyRecord,
  IdempotencyReservation,
  IdempotencyStore,
} from "../../application/ports/idempotency-store.js";

type Entry = {
  record: IdempotencyRecord<unknown>;
  expiresAt: number;
};

type Claim = {
  expiresAt: number;
};

/**
 * Disposable idempotency storage. The API mirrors the Redis adapter that will
 * replace it: lookup by key, save with a TTL, an atomic claim, lazy expiry.
 *
 * "Atomic" here is honest for one Node process because `acquire` checks and
 * writes without yielding; Redis gets the same guarantee from `SET NX`.
 */
export function createInMemoryIdempotencyStore(
  now: () => number = Date.now,
): IdempotencyStore {
  const entries = new Map<string, Entry>();
  const claims = new Map<string, Claim>();

  return {
    async find<TResult>(key: string) {
      const entry = entries.get(key);

      if (entry === undefined) {
        return null;
      }

      if (entry.expiresAt <= now()) {
        entries.delete(key);
        return null;
      }

      return structuredClone(entry.record) as IdempotencyRecord<TResult>;
    },

    async save<TResult>(
      key: string,
      record: IdempotencyRecord<TResult>,
      ttlSeconds: number,
    ) {
      entries.set(key, {
        record: structuredClone(record),
        expiresAt: now() + ttlSeconds * 1000,
      });
      claims.delete(key);
    },

    async acquire(
      key: string,
      ttlSeconds: number,
    ): Promise<IdempotencyReservation> {
      const current = claims.get(key);
      const timestamp = now();

      if (current !== undefined && current.expiresAt > timestamp) {
        return "busy";
      }

      claims.set(key, { expiresAt: timestamp + ttlSeconds * 1000 });
      return "acquired";
    },

    async release(key: string) {
      claims.delete(key);
    },
  };
}
```

```typescript
import { Kafka, Partitioners, type Producer } from "kafkajs";
import type { EventPublisher } from "../../application/ports/event-publisher.js";
import { toKafkaMessage } from "./kafka-messages.js";

export type KafkaEventPublisherOptions = {
  brokers: string[];
  clientId: string;
  /** Producer acks. `all` waits for the in-sync replicas. */
  acks?: number;
};

export type KafkaEventPublisher = EventPublisher & {
  connect(): Promise<void>;
  disconnect(): Promise<void>;
};

/**
 * Kafka is one possible *reader* of the outbox. The dispatcher still decides
 * when an event is delivered; this adapter only decides how it travels:
 * topic, partition key, JSON body, headers.
 *
 * The producer connects lazily on the first publish, so a broker that is down
 * fails the delivery (and the outbox retries it) instead of the whole process.
 */
export function createKafkaEventPublisher({
  brokers,
  clientId,
  acks = -1,
}: KafkaEventPublisherOptions): KafkaEventPublisher {
  const kafka = new Kafka({
    clientId,
    brokers,
    retry: { retries: 5, initialRetryTime: 200 },
  });

  const producer: Producer = kafka.producer({
    allowAutoTopicCreation: true,
    createPartitioner: Partitioners.DefaultPartitioner,
  });
  let connection: Promise<void> | null = null;

  const connect = async (): Promise<void> => {
    if (connection === null) {
      connection = producer.connect().catch((error: unknown) => {
        // A failed connect must not be cached as success.
        connection = null;
        throw error;
      });
    }

    await connection;
  };

  return {
    async publish(event, envelope) {
      await connect();
      const message = toKafkaMessage(event, envelope);

      await producer.send({
        topic: message.topic,
        acks,
        messages: [
          {
            ...(message.key === null ? {} : { key: message.key }),
            value: message.value,
            headers: message.headers,
          },
        ],
      });
    },

    connect,

    async disconnect() {
      if (connection !== null) {
        await producer.disconnect();
        connection = null;
      }
    },
  };
}
```

```typescript
import type { DomainEvent } from "../../domain/shared/domain-event.js";

/**
 * Topic names and partition keys belong to the broker world. Keeping the
 * mapping in one pure module means the application never learns a topic name,
 * and the routing is testable without a broker.
 */
export const ORDER_TOPIC = "ecommerce.orders.v1";
export const CUSTOMER_TOPIC = "ecommerce.customers.v1";

export const DEFAULT_TOPIC = "ecommerce.events.v1";

const TOPICS: Record<string, string> = {
  "customer.registered": CUSTOMER_TOPIC,
  "order.created": ORDER_TOPIC,
  "order.paid": ORDER_TOPIC,
  "order.cancelled": ORDER_TOPIC,
};

/** Declared once, created at start-up, so a consumer never races a topic. */
export const KAFKA_TOPICS = [ORDER_TOPIC, CUSTOMER_TOPIC, DEFAULT_TOPIC];

export type KafkaMessage = {
  topic: string;
  key: string | null;
  value: string;
  headers: Record<string, string>;
};

export function topicForEvent(name: string): string {
  return TOPICS[name] ?? DEFAULT_TOPIC;
}

/**
 * Orders are partitioned by order id, so all events for one order land on the
 * same partition and reach a consumer in order. Customer events fall back to
 * the customer id for the same reason.
 */
export function partitionKeyForEvent(event: DomainEvent): string | null {
  const candidate = event.payload["orderId"] ?? event.payload["customerId"];

  return typeof candidate === "string" ? candidate : null;
}

export function toKafkaMessage(
  event: DomainEvent,
  envelope: { id: string },
): KafkaMessage {
  return {
    topic: topicForEvent(event.name),
    key: partitionKeyForEvent(event),
    value: JSON.stringify({
      id: envelope.id,
      name: event.name,
      occurredAt: event.occurredAt,
      payload: event.payload,
    }),
    headers: {
      "x-event-id": envelope.id,
      "x-event-name": event.name,
      "x-event-version": "1",
    },
  };
}
```

```typescript
import { Kafka } from "kafkajs";
import { KAFKA_TOPICS } from "./kafka-messages.js";

export type EnsureKafkaTopicsOptions = {
  brokers: string[];
  clientId: string;
  topics?: string[];
  numPartitions?: number;
};

/**
 * Topic creation belongs to the broker side of the world and belongs at
 * start-up, before any consumer subscribes. Relying on auto-creation leaves a
 * race: the first consumer can be rejected with "this server does not host
 * this topic-partition" while the topic is still being created.
 *
 * Existing topics are left alone, so this is safe to run on every boot.
 */
export async function ensureKafkaTopics({
  brokers,
  clientId,
  topics = KAFKA_TOPICS,
  numPartitions = 3,
}: EnsureKafkaTopicsOptions): Promise<void> {
  const kafka = new Kafka({
    clientId: `${clientId}-admin`,
    brokers,
    retry: { retries: 5, initialRetryTime: 200 },
  });
  const admin = kafka.admin();

  await admin.connect();

  try {
    const existing = new Set(await admin.listTopics());
    const missing = topics.filter((topic) => !existing.has(topic));

    if (missing.length === 0) {
      return;
    }

    await admin.createTopics({
      waitForLeaders: true,
      topics: missing.map((topic) => ({
        topic,
        numPartitions,
        replicationFactor: 1,
      })),
    });
  } finally {
    await admin.disconnect();
  }
```

```typescript
import { Kafka, type Consumer, type EachMessagePayload } from "kafkajs";
import { CUSTOMER_TOPIC, ORDER_TOPIC } from "./kafka-messages.js";

export type ConsumedEvent = {
  id: string;
  name: string;
  occurredAt: string;
  payload: Record<string, unknown>;
};

export type OrderEventsConsumerOptions = {
  brokers: string[];
  clientId: string;
  groupId: string;
  topics?: string[];
  /** Where a decoded event goes. The default logs one structured line. */
  onEvent?: (event: ConsumedEvent) => Promise<void> | void;
  onError?: (error: unknown) => void;
};

export type OrderEventsConsumer = {
  start(): Promise<void>;
  stop(): Promise<void>;
};

const DEFAULT_TOPICS = [ORDER_TOPIC, CUSTOMER_TOPIC];

/**
 * A consumer that is deliberately idempotent: delivery is at-least-once, so
 * the same `x-event-id` can arrive twice. Recent ids are remembered and
 * duplicates are acknowledged without being handled again.
 *
 * The dedupe set is per-process and bounded. A real projection would persist
 * processed ids in the same database transaction as the projection update
 * (the inbox pattern); this keeps the shape visible without pretending.
 */
export function createOrderEventsConsumer({
  brokers,
  clientId,
  groupId,
  topics = DEFAULT_TOPICS,
  onEvent = (event) => {
    console.log(
      JSON.stringify({
        consumer: "order-events",
        event: event.name,
        id: event.id,
      }),
    );
  },
  onError = (error) => console.error("Kafka consumer error", error),
}: OrderEventsConsumerOptions): OrderEventsConsumer {
  const kafka = new Kafka({ clientId, brokers, retry: { retries: 5 } });
  const consumer: Consumer = kafka.consumer({
    groupId,
    allowAutoTopicCreation: true,
  });
  const seen: string[] = [];
  const seenIds = new Set<string>();
  const MAX_SEEN = 1_000;

  const remember = (id: string): boolean => {
    if (seenIds.has(id)) {
      return false;
    }

    seenIds.add(id);
    seen.push(id);

    if (seen.length > MAX_SEEN) {
      const evicted = seen.shift();
      if (evicted !== undefined) {
        seenIds.delete(evicted);
      }
    }

    return true;
  };

  const handle = async ({ message }: EachMessagePayload): Promise<void> => {
    const headerId = message.headers?.["x-event-id"];
    const raw = message.value?.toString() ?? "";
    let parsed: ConsumedEvent;

    try {
      parsed = JSON.parse(raw) as ConsumedEvent;
    } catch (error) {
      onError(error);
      return;
    }

    const id =
      typeof headerId === "string"
        ? headerId
        : (headerId?.toString() ?? parsed.id);

    if (!remember(id)) {
      return;
    }

    await onEvent({ ...parsed, id });
  };

  return {
    async start() {
      await consumer.connect();
      await consumer.subscribe({ topics, fromBeginning: false });
      await consumer.run({ eachMessage: handle });
    },

    async stop() {
      await consumer.disconnect();
    },
  };
}
```

```typescript
export type CheckoutMetricOutcome =
  "completed" | "replayed" | "declined" | "in_progress" | "failed";

export type Metrics = {
  registry: Registry;
  observeHttpRequest(input: {
    method: string;
    route: string;
    statusCode: number;
    durationSeconds: number;
  }): void;
  recordCheckout(outcome: CheckoutMetricOutcome): void;
  recordOutboxDelivery(published: number, failed: number): void;
  render(): Promise<string>;
  contentType: string;
};

/**
 * Metrics are an infrastructure concern: the application returns meaningful
 * outcomes, and this module turns them into series. Cardinality is bounded by
 * using the *route pattern*, never the raw URL.
 */
export function createMetrics(): Metrics {
  const registry = new Registry();
  collectDefaultMetrics({ register: registry });

  const httpRequests = new Counter({
    name: "http_requests_total",
    help: "HTTP requests by method, route, and status",
    labelNames: ["method", "route", "status"] as const,
    registers: [registry],
  });

  const httpDuration = new Histogram({
    name: "http_request_duration_seconds",
    help: "HTTP request duration in seconds",
    labelNames: ["method", "route", "status"] as const,
    buckets: [0.005, 0.01, 0.025, 0.05, 0.1, 0.25, 0.5, 1, 2.5, 5],
    registers: [registry],
  });

  const checkout = new Counter({
    name: "checkout_total",
    help: "Checkout attempts by outcome",
    labelNames: ["outcome"] as const,
    registers: [registry],
  });

  const outbox = new Counter({
    name: "outbox_messages_total",
    help: "Outbox messages by delivery result",
    labelNames: ["result"] as const,
    registers: [registry],
  });

  return {
    registry,
    contentType: registry.contentType,

    observeHttpRequest({ method, route, statusCode, durationSeconds }) {
      const labels = {
        method,
        route,
        status: String(statusCode),
      };

      httpRequests.inc(labels);
      httpDuration.observe(labels, durationSeconds);
    },

    recordCheckout(outcome) {
      checkout.inc({ outcome });
    },

    recordOutboxDelivery(published, failed) {
      if (published > 0) {
        outbox.inc({ result: "published" }, published);
      }

      if (failed > 0) {
        outbox.inc({ result: "failed" }, failed);
      }
    },

    render() {
      return registry.metrics();
    },
  };
}
```

```typescript
import type { DispatchOutbox } from "../../application/outbox/dispatch-outbox.types.js";

export type OutboxWorkerOptions = {
  dispatch: DispatchOutbox;
  intervalMs: number;
  onError?: (error: unknown) => void;
};

export type OutboxWorker = {
  start(): void;
  stop(): Promise<void>;
  /** Runs one poll immediately; useful for tests and for shutdown flushing. */
  runOnce(): Promise<void>;
};

/**
 * The scheduling half of the outbox. It knows nothing about events, only when
 * to ask the application to drain a batch. A cron job or a queue-based worker
 * can replace it without touching the dispatcher.
 */
export function createOutboxWorker({
  dispatch,
  intervalMs,
  onError = (error) => console.error("Outbox dispatch failed", error),
}: OutboxWorkerOptions): OutboxWorker {
  let timer: ReturnType<typeof setInterval> | null = null;
  let inFlight: Promise<void> | null = null;
  let stopped = false;

  const poll = async (): Promise<void> => {
    if (inFlight !== null) {
      return inFlight;
    }

    inFlight = (async () => {
      const result = await dispatch();

      if (!result.ok) {
        onError(result.error);
      }
    })()
      .catch(onError)
      .finally(() => {
        inFlight = null;
      });

    return inFlight;
  };

  return {
    start() {
      if (timer !== null || stopped) {
        return;
      }

      timer = setInterval(() => {
        void poll();
      }, intervalMs);
    },

    async runOnce() {
      await poll();
    },

    async stop() {
      stopped = true;

      if (timer !== null) {
        clearInterval(timer);
        timer = null;
      }

      if (inFlight !== null) {
        await inFlight;
      }
    },
  };
}
```

```typescript
import type {
  PaymentGateway,
  PaymentGatewayRequest,
} from "../../application/ports/payment-gateway.js";

export type InMemoryPaymentGatewayOptions = {
  /** Decide declines per request; by default every charge succeeds. */
  declineWhen?: (request: PaymentGatewayRequest) => boolean;
  referencePrefix?: string;
};

/**
 * A gateway for local runs and tests: deterministic references, no network,
 * and a decline hook so the failure path is reachable. Stripe (or any real
 * processor) implements the same port.
 *
 * Charges are remembered by idempotency key, mirroring how a real provider
 * protects a retried request from taking money twice.
 */
export function createInMemoryPaymentGateway(
  options: InMemoryPaymentGatewayOptions = {},
): PaymentGateway {
  const prefix = options.referencePrefix ?? "test";
  const references = new Map<string, string>();

  return {
    async charge(request) {
      const previous = references.get(request.idempotencyKey);

      if (previous !== undefined) {
        return { ok: true, value: { providerReference: previous } };
      }

      if (options.declineWhen?.(request) === true) {
        return {
          ok: false,
          error: {
            type: "payment_declined",
            message: "Card was declined by the payment gateway",
          },
        };
      }

      const providerReference = `${prefix}_${references.size + 1}`;
      references.set(request.idempotencyKey, providerReference);

      return {
        ok: true,
        value: { providerReference },
      };
    },
  };
}
```

```typescript
import { MongoClient, type Db } from "mongodb";

export type MongoConnection = {
  client: MongoClient;
  db: Db;
  close(): Promise<void>;
};

export type MongoConnectionOptions = {
  uri: string;
  database: string;
  serverSelectionTimeoutMS?: number;
};

/**
 * Opens the connection, creates the indexes the repositories rely on, and
 * returns a handle the composition root can close. Indexes are created at
 * start-up because the in-memory adapters had none to create.
 */
export async function connectMongo({
  uri,
  database,
  serverSelectionTimeoutMS = 10_000,
}: MongoConnectionOptions): Promise<MongoConnection> {
  const client = new MongoClient(uri, {
    serverSelectionTimeoutMS,
    appName: "ecommerce-backend",
    // Never persist `undefined`; documents hold explicit nulls instead.
    ignoreUndefined: true,
  });

  try {
    await client.connect();
    const db = client.db(database);
    await ensureIndexes(db);

    return {
      client,
      db,
      close: async () => {
        await client.close();
      },
    };
  } catch (error) {
    await client.close().catch(() => undefined);
    throw error;
  }
}

/**
 * Unique indexes enforce rules the in-memory adapters only implied:
 * one customer per email, one stock record per product. The outbox index makes
 * `findPending` a bounded, ordered scan.
 */
async function ensureIndexes(db: Db): Promise<void> {
  await Promise.all([
    db.collection("customers").createIndex({ email: 1 }, { unique: true }),
    db.collection("inventory").createIndex({ productId: 1 }, { unique: true }),
    db.collection("carts").createIndex({ customerId: 1 }, { unique: true }),
    db.collection("orders").createIndex({ customerId: 1 }),
    db.collection("outbox").createIndex({ publishedAt: 1, createdAt: 1 }),
  ]);
}
```

```typescript
import type { Db } from "mongodb";
import type { OutboxRepository } from "../../../application/ports/outbox.js";
import {
  fromOutboxDocument,
  toOutboxDocument,
  type OutboxDocument,
} from "./mongo-documents.js";
import { sessionOptions } from "./mongo-session.js";

/**
 * The outbox collection is written through the same session as the business
 * write, which is what makes "state + event" a single commit. `findPending`
 * runs outside any transaction, because delivery happens after the commit.
 */
export function createMongoOutboxRepository(db: Db): OutboxRepository {
  const outbox = db.collection<OutboxDocument>("outbox");

  return {
    async add(message) {
      await outbox.insertOne(toOutboxDocument(message), sessionOptions());
    },

    async findPending(limit) {
      const docs = await outbox
        .find({ publishedAt: null })
        .sort({ createdAt: 1, _id: 1 })
        .limit(limit)
        .toArray();
      return docs.map(fromOutboxDocument);
    },

    async markPublished(id, publishedAt) {
      await outbox.updateOne(
        { _id: id },
        { $set: { publishedAt, lastError: null } },
      );
    },

    async markFailed(id, error) {
```

```typescript
/**
 * Propagates the transaction's session to the repositories that participate in
 * it, without threading a `session` argument through every port.
 *
 * The boundary is still explicit where it matters — the use case calls
 * `unitOfWork.execute(...)` — and only this layer knows how the session
 * reaches the driver. A repository called outside a transaction simply gets no
 * session and runs on its own.
 */
const storage = new AsyncLocalStorage<ClientSession>();

export function runWithMongoSession<T>(
  session: ClientSession,
  work: () => Promise<T>,
): Promise<T> {
  return storage.run(session, work);
}

export function currentMongoSession(): ClientSession | undefined {
  return storage.getStore();
}

/** Spread into driver options so the operation joins the active transaction. */
export function sessionOptions(): { session?: ClientSession } {
  const session = currentMongoSession();

  return session === undefined ? {} : { session };
```

```typescript
import { MongoError, type ClientSession, type MongoClient } from "mongodb";
import type {
  UnitOfWork,
  UnitOfWorkError,
} from "../../../application/ports/unit-of-work.js";
import type { Result } from "../../../domain/shared/result.js";
import { runWithMongoSession } from "./mongo-session.js";

/** A write conflict means the work should be re-run, not reported as failed. */
const MAX_ATTEMPTS = 3;

function messageOf(error: unknown): string {
  return error instanceof Error ? error.message : "Unknown transaction failure";
}

function isTransient(error: unknown): boolean {
  if (!(error instanceof MongoError)) {
    return false;
  }

  // `codeName` is on server errors, which the base class type does not model.
  const codeName = (error as { codeName?: string }).codeName;

  return (
    error.hasErrorLabel("TransientTransactionError") ||
    codeName === "WriteConflict" ||
    codeName === "NoSuchTransaction"
  );
}

async function abortQuietly(session: ClientSession): Promise<void> {
  try {
    await session.abortTransaction();
  } catch {
    // Already aborted or already committed; nothing left to undo.
  }
}

/**
 * MongoDB transactions need a replica set — the compose file runs a
 * single-node one, which is enough for real atomicity here.
 *
 * Commit happens only when the work returns `ok`. A business failure aborts;
 * a thrown error aborts and becomes `transaction_failed`; a transient write
 * conflict (two checkouts claiming the same stock) re-runs the work against
 * fresh data, up to three times. That last part is what a snapshot in memory
 * cannot model.
 */
export function createMongoUnitOfWork(client: MongoClient): UnitOfWork {
  return {
    async execute<T, E>(
      work: () => Promise<Result<T, E>>,
    ): Promise<Result<T, E | UnitOfWorkError>> {
      let lastError: unknown = null;

      for (let attempt = 1; attempt <= MAX_ATTEMPTS; attempt += 1) {
        const session = client.startSession();

        try {
          session.startTransaction({
            readConcern: { level: "snapshot" },
            writeConcern: { w: "majority" },
          });

          const result = await runWithMongoSession(session, work);

          if (result.ok) {
            await session.commitTransaction();
          } else {
            await abortQuietly(session);
          }

          return result;
        } catch (error) {
          lastError = error;
          await abortQuietly(session);

          if (isTransient(error) && attempt < MAX_ATTEMPTS) {
            continue;
          }

          return {
            ok: false,
            error: { type: "transaction_failed", message: messageOf(error) },
          };
        } finally {
          await session.endSession();
        }
      }

      return {
        ok: false,
        error: { type: "transaction_failed", message: messageOf(lastError) },
      };
    },
  };
}
```

```typescript
import type {
  RateLimitDecision,
  RateLimiter,
} from "../../application/ports/rate-limiter.js";

export type InMemoryRateLimiterOptions = {
  limit: number;
  windowSeconds: number;
  /** Injectable so tests can move time without sleeping. */
  now?: () => number;
};

type Window = {
  count: number;
  resetAt: number;
};

/**
 * A per-process fixed window: correct for one instance, and the fallback when
 * Redis is not configured. With several instances it undercounts, which is why
 * the Redis adapter exists.
 */
export function createInMemoryRateLimiter({
  limit,
  windowSeconds,
  now = Date.now,
}: InMemoryRateLimiterOptions): RateLimiter {
  const windows = new Map<string, Window>();
  const windowMs = windowSeconds * 1000;

  return {
    async consume(key): Promise<RateLimitDecision> {
      const timestamp = now();
      const existing = windows.get(key);

      if (existing === undefined || existing.resetAt <= timestamp) {
        windows.set(key, { count: 1, resetAt: timestamp + windowMs });

        return {
          allowed: true,
          limit,
          remaining: Math.max(0, limit - 1),
          resetInSeconds: windowSeconds,
        };
      }

      existing.count += 1;

      return {
        allowed: existing.count <= limit,
        limit,
        remaining: Math.max(0, limit - existing.count),
        resetInSeconds: Math.max(
          1,
          Math.ceil((existing.resetAt - timestamp) / 1000),
        ),
      };
    },
  };
}
```

```typescript
        JSON.stringify(value),
        "EX",
        ttlSeconds,
      );
    },

    async delete(key: string): Promise<void> {
      await client.del(`${prefix}${key}`);

  };
```

```typescript
import type { Redis } from "ioredis";
import type {
  IdempotencyRecord,
  IdempotencyReservation,
  IdempotencyStore,
} from "../../application/ports/idempotency-store.js";

const RECORD_PREFIX = "idempotency:record:";
const CLAIM_PREFIX = "idempotency:claim:";

/**
 * `SET NX EX` is the whole trick: the first request to claim a key wins, and
 * every concurrent retry gets `busy` instead of running the checkout again.
 *
 * The claim and the record are separate keys on purpose. Saving the record
 * removes the claim, so a *completed* retry replays, while an *in-flight*
 * retry is refused with 409 rather than double-charging.
 */
export function createRedisIdempotencyStore(client: Redis): IdempotencyStore {
  return {
    async find<TResult>(key: string) {
      const raw = await client.get(`${RECORD_PREFIX}${key}`);

      if (raw === null) {
        return null;
      }

      try {
        return JSON.parse(raw) as IdempotencyRecord<TResult>;
      } catch {
        return null;
      }
    },

    async save<TResult>(
      key: string,
      record: IdempotencyRecord<TResult>,
      ttlSeconds: number,
    ) {
      await client
        .multi()
        .set(`${RECORD_PREFIX}${key}`, JSON.stringify(record), "EX", ttlSeconds)
        .del(`${CLAIM_PREFIX}${key}`)
        .exec();
    },

    async acquire(
      key: string,
      ttlSeconds: number,
    ): Promise<IdempotencyReservation> {
      const result = await client.set(
        `${CLAIM_PREFIX}${key}`,
        "1",
        "EX",
        ttlSeconds,
        "NX",
      );

      return result === "OK" ? "acquired" : "busy";
    },

    async release(key: string) {
      await client.del(`${CLAIM_PREFIX}${key}`);
    },
  };
}
```

```typescript
import type {
  RateLimitDecision,
  RateLimiter,

/**
 * INCR plus EXPIRE must be one step, otherwise a crash between them leaves a
 * counter with no window and the caller is limited forever. A short Lua script
 * runs atomically inside Redis.
 */
const LUA = `
local count = redis.call('INCR', KEYS[1])
if count == 1 then
  redis.call('EXPIRE', KEYS[1], ARGV[1])
end
local ttl = redis.call('TTL', KEYS[1])
return { count, ttl }
`;

export type RedisRateLimiterOptions = {
  limit: number;
  windowSeconds: number;
  prefix?: string;
};

export function createRedisRateLimiter(
  client: Redis,
  { limit, windowSeconds, prefix = "ratelimit:" }: RedisRateLimiterOptions,
): RateLimiter {
  return {
    async consume(key): Promise<RateLimitDecision> {
      const response = (await client.eval(
        LUA,
        1,
        `${prefix}${key}`,
        windowSeconds,
      )) as [number, number];

      const count = response[0] ?? 0;
      const ttl = response[1] ?? windowSeconds;

      return {
        allowed: count <= limit,
        limit,
        remaining: Math.max(0, limit - count),
        resetInSeconds: ttl > 0 ? ttl : windowSeconds,
      };
    },
  };
}
```

```typescript
import type {
  UnitOfWork,
  UnitOfWorkError,
} from "../../application/ports/unit-of-work.js";
import type { Result } from "../../domain/shared/result.js";
import type { InMemoryStoreRef } from "../persistence/in-memory/store.js";

/**
 * A real transaction boundary over in-memory maps, not a try/catch facade:
 *
 *   1. snapshot the whole store
 *   2. let the work write to a private copy
 *   3. keep the copy only when the work reports success
 *   4. restore the snapshot on failure or on a thrown error
 *
 * Transactions are serialised through a promise queue so two of them cannot
 * both claim the same stock. A PostgreSQL implementation gets this for free
 * from the database; the application code cannot tell which one it has.
 */
export function createInMemoryUnitOfWork(store: InMemoryStoreRef): UnitOfWork {
  let tail: Promise<unknown> = Promise.resolve();

  return {
    execute<T, E>(
      work: () => Promise<Result<T, E>>,
    ): Promise<Result<T, E | UnitOfWorkError>> {
      const run = async (): Promise<Result<T, E | UnitOfWorkError>> => {
        const snapshot = structuredClone(store.current);

        try {
          const result = await work();

          if (!result.ok) {
            store.current = snapshot;
          }

          return result;
        } catch (error) {
          store.current = snapshot;

          return {
            ok: false,
            error: {
              type: "transaction_failed",
              message:
                error instanceof Error
                  ? error.message
                  : "The transaction could not be completed",
            },
          };
        }
      };

      const settled = tail.then(run, run);
      tail = settled.then(
        () => undefined,
        () => undefined,
      );

      return settled;
    },
  };
}
```

```typescript
/**
 * The default adapter set: in-process, disposable, no external services.
 *
 * One store is shared by every repository and by the transaction adapter, so a
 * rollback can restore exactly the state the transaction started from.
 */
export function buildInMemoryDependencies(): ContainerDependencies {
  const store = createInMemoryStore();

  return {
    customers: createInMemoryCustomerRepository(store),
    products: createInMemoryProductRepository(store),
    inventory: createInMemoryInventoryRepository(store),
    carts: createInMemoryCartRepository(store),
    orders: createInMemoryOrderRepository(store),
    outbox: createInMemoryOutboxRepository(store),
    cache: createInMemoryCache(),
    clock: createSystemClock(),
    ids: createUuidGenerator(),
    events: createConsoleEventPublisher(),
    gateway: createInMemoryPaymentGateway(),
    idempotency: createInMemoryIdempotencyStore(),
    unitOfWork: createInMemoryUnitOfWork(store),
  };
}

export type ContainerOptions = {
  /** `null` keeps the in-memory adapters, which is the default for tests. */
  mongodb: { uri: string; database: string } | null;
  /** `null` keeps the in-memory cache, idempotency, and rate limiter. */
  redis: { url: string } | null;
  /** `null` publishes to stdout and runs no consumer. */
  kafka: {
    brokers: string[];
    clientId: string;
    consumerGroup: string;
  } | null;
  rateLimit: { max: number; windowSeconds: number };
};

export type Container = {
  useCases: UseCases;
  controllers: HttpControllers;
  metrics: Metrics;
  rateLimiter: RateLimiter;
  healthChecks: HealthCheck[];
  /** Connects background consumers. Safe to call once. */
  start(): Promise<void>;
  /** Releases connections in reverse order of acquisition. */
  close(): Promise<void>;
};

/**
 * The single place that decides which adapter each port receives, and the only
 * module that knows every world at once: the application graph, persistence,
 * cache, broker, and metrics.
 *
 * Selection is configuration, not code branching inside the application:
 *
 *   MONGODB_URI  → Mongo repositories + transactional unit of work
 *   REDIS_URL    → Redis cache, atomic idempotency, shared rate limiting
 *   KAFKA_BROKERS→ Kafka producer behind the outbox + an idempotent consumer
 */
export async function buildContainer({
  mongodb,
  redis,
  kafka,
  rateLimit,
}: ContainerOptions): Promise<Container> {
  const metrics = createMetrics();
  const healthChecks: HealthCheck[] = [];
  const shutdown: (() => Promise<void>)[] = [];

  let persistence: Awaited<ReturnType<typeof buildMongoPersistence>> | null =
    null;
  let cache: Cache = createInMemoryCache();
  let idempotency: IdempotencyStore = createInMemoryIdempotencyStore();
  let rateLimiter: RateLimiter = createInMemoryRateLimiter({
    limit: rateLimit.max,
    windowSeconds: rateLimit.windowSeconds,
  });
  let events: EventPublisher = createConsoleEventPublisher();
  let kafkaPublisher: KafkaEventPublisher | null = null;
  let consumer: OrderEventsConsumer | null = null;

  if (mongodb !== null) {
    persistence = await buildMongoPersistence(mongodb);
    const connection = persistence;

    healthChecks.push({ name: "mongodb", check: () => connection.check() });
    shutdown.push(() => connection.close());
  }

  if (redis !== null) {
    const connection = await connectRedis(redis.url);

    cache = createRedisCache(connection.client);
    idempotency = createRedisIdempotencyStore(connection.client);
    rateLimiter = createRedisRateLimiter(connection.client, {
      limit: rateLimit.max,
      windowSeconds: rateLimit.windowSeconds,
    });

    healthChecks.push({ name: "redis", check: () => connection.check() });
    shutdown.push(() => connection.close());
  }

  if (kafka !== null) {
    kafkaPublisher = createKafkaEventPublisher({
      brokers: kafka.brokers,
      clientId: kafka.clientId,
    });
    events = kafkaPublisher;

    consumer = createOrderEventsConsumer({
      brokers: kafka.brokers,
      clientId: kafka.clientId,
      groupId: kafka.consumerGroup,
    });

    healthChecks.push({
      name: "kafka",
      check: async () => {
        await kafkaPublisher?.connect();
      },
    });

    shutdown.push(async () => {
      try {
        await consumer?.stop();
      } catch {
        // The consumer may never have connected; disconnecting is best effort.
      }
      await kafkaPublisher?.disconnect();
    });
  }

  const ports: ContainerDependencies =
    persistence === null
      ? { ...buildInMemoryDependencies(), cache, events, idempotency }
      : {
          ...persistence,
          cache,
          clock: createSystemClock(),
          ids: createUuidGenerator(),
          events,
          gateway: createInMemoryPaymentGateway(),
          idempotency,
        };

  const wired = buildUseCases(ports);

  // Metrics wrap outcomes, not layers: the use cases stay unaware of them.
  const useCases: UseCases = {
    ...wired,
    checkout: async (input) => {
      const result = await wired.checkout(input);

      if (result.ok) {
        metrics.recordCheckout(
          result.value.replayed ? "replayed" : "completed",
        );
      } else {
        const outcome =
          result.error.type === "payment_declined"
            ? "declined"
            : result.error.type === "checkout_in_progress"
              ? "in_progress"
              : "failed";

        metrics.recordCheckout(outcome);
      }

      return result;
    },
    dispatchOutbox: async () => {
      const result = await wired.dispatchOutbox();

      if (result.ok) {
        metrics.recordOutboxDelivery(
          result.value.published,
          result.value.failed,
        );
      }

      return result;
    },
  };

  return {
    useCases,
    controllers: buildControllers(useCases),
    metrics,
    rateLimiter,
    healthChecks,

    async start() {
      if (kafka !== null) {
        try {
          await ensureKafkaTopics({
            brokers: kafka.brokers,
            clientId: kafka.clientId,
          });
        } catch (error) {
          console.error(
            "Kafka topic bootstrap failed; relying on auto-create",
            error,
          );
        }
      }

      if (consumer === null) {
        return;
      }

      try {
        await consumer.start();
      } catch (error) {
        // The outbox keeps retrying; a consumer that cannot start should not
        // take the HTTP API down with it.
        console.error(
          "Kafka consumer failed to start; outbox delivery will retry",
          error,
        );
      }
    },

    async close() {
      for (const release of [...shutdown].reverse()) {
        try {
          await release();
        } catch (error) {
          console.error("Shutdown step failed", error);
        }
      }
    },
  };
}
```

```typescript
import type { FastifyInstance } from "fastify";
import { loadConfig } from "../infrastructure/config/config.js";
import { buildHttpApp } from "../infrastructure/http/fastify.js";
import {
  createOutboxWorker,
  type OutboxWorker,
} from "../infrastructure/outbox/outbox-worker.js";
import { buildContainer } from "./container.js";

/** One shutdown path for both termination signals. */
function registerShutdown(
  app: FastifyInstance,
  worker: OutboxWorker,
  closeContainer: () => Promise<void>,
): void {
  const shutdown = async (signal: NodeJS.Signals): Promise<void> => {
    app.log.info({ signal }, "Shutting down");
    await worker.stop();
    await app.close();
    await closeContainer();
    process.exit(0);
  };

  for (const signal of ["SIGINT", "SIGTERM"] as const) {
    process.once(signal, () => {
      void shutdown(signal);
    });
  }
}

async function start(): Promise<void> {
  const config = loadConfig();

  if (!config.ok) {
    console.error(config.error.message);
    process.exitCode = 1;
    return;
  }

  let container;

  try {
    container = await buildContainer({
      mongodb:
        config.value.mongodbUri === null
          ? null
          : {
              uri: config.value.mongodbUri,
              database: config.value.mongodbDatabase,
            },
      redis:
        config.value.redisUrl === null ? null : { url: config.value.redisUrl },
      kafka:
        config.value.kafkaBrokers === null
          ? null
          : {
              brokers: config.value.kafkaBrokers,
              clientId: config.value.kafkaClientId,
              consumerGroup: config.value.kafkaConsumerGroup,
            },
      rateLimit: config.value.rateLimit,
    });
  } catch (error) {
    console.error(
      "Could not start the configured adapters:",
      error instanceof Error ? error.message : error,
    );
    process.exitCode = 1;
    return;
  }

  const { controllers, useCases, close } = container;

  const worker = createOutboxWorker({
    dispatch: useCases.dispatchOutbox,
    intervalMs: config.value.outboxPollIntervalMs,
  });

  const app = buildHttpApp({
    controllers,
    rateLimiter: container.rateLimiter,
    metrics: container.metrics,
    healthChecks: container.healthChecks,
  });

  app.log.info(
    {
      persistence: config.value.mongodbUri === null ? "memory" : "mongodb",
      cache: config.value.redisUrl === null ? "memory" : "redis",
      events: config.value.kafkaBrokers === null ? "stdout" : "kafka",
      rateLimit: config.value.rateLimit,
    },
    "Adapters selected",
  );

  await container.start();
  worker.start();
  registerShutdown(app, worker, close);

  try {
    await app.listen({ port: config.value.port, host: "0.0.0.0" });
  } catch (error) {
    app.log.error(error);
    await worker.stop();
    await app.close();
    await close();
    process.exitCode = 1;
  }
}

await start();
```

```typescript
import { readFileSync, readdirSync, statSync } from "node:fs";
import { join, relative } from "node:path";
import { fileURLToPath } from "node:url";
import { describe, expect, it } from "vitest";

/**
 * The lint rules catch imports by path pattern. This test catches them by
 * reading the files, so a new framework import or a `process.env` access in
 * the wrong layer fails even if someone edits the ESLint config.
 */
const SRC = fileURLToPath(new URL("../../src", import.meta.url));

const FRAMEWORKS = [
  "fastify",
  "zod",
  "@prisma/client",
  "ioredis",
  "kafkajs",
  "@aws-sdk/",
  "stripe",
];

function filesUnder(directory: string): string[] {
  return readdirSync(directory).flatMap((entry) => {
    const path = join(directory, entry);

    return statSync(path).isDirectory()
      ? filesUnder(path)
      : path.endsWith(".ts")
        ? [path]
        : [];
  });
}

/** Comments describe the rule; only code can break it. */
function codeOnly(contents: string): string {
  return contents.replace(/\/\*[\s\S]*?\*\//g, "").replace(/\/\/.*$/gm, "");
}

function specifiersOf(contents: string): string[] {
  const matches = contents.matchAll(/(?:from\s+|import\s*)["']([^"']+)["']/g);
  return [...matches].map((match) => match[1] ?? "").filter(Boolean);
}

function layer(name: string): { path: string; contents: string }[] {
  return filesUnder(join(SRC, name)).map((path) => ({
    path: relative(SRC, path),
    contents: readFileSync(path, "utf8"),
  }));
}

function forbidden(
  source: { path: string; contents: string }[],
  patterns: string[],
  allowBare = false,
): string[] {
  const violations: string[] = [];

  for (const file of source) {
    for (const specifier of specifiersOf(file.contents)) {
      const bare = !specifier.startsWith(".");

      if (bare && !allowBare) {
        violations.push(`${file.path} imports package "${specifier}"`);
        continue;
      }

      if (patterns.some((pattern) => specifier.includes(pattern))) {
        violations.push(`${file.path} imports "${specifier}"`);
      }
    }
  }

  return violations;
}

describe("dependency rule", () => {
  it("keeps domain free of outer layers, frameworks, and the Node runtime", () => {
    const violations = forbidden(layer("domain"), [
      "/application/",
      "/infrastructure/",
      "/main/",
      ...FRAMEWORKS,
      "node:",
    ]);

    expect(violations).toEqual([]);
  });

  it("keeps application free of infrastructure, frameworks, and the runtime", () => {
    const violations = forbidden(layer("application"), [
      "/infrastructure/",
      "/main/",
      ...FRAMEWORKS,
      "node:",
    ]);

    expect(violations).toEqual([]);
  });

  it("keeps adapters free of the composition root", () => {
    // Adapters legitimately import frameworks and the Node runtime.
    const violations = forbidden(layer("infrastructure"), ["/main/"], true);

    expect(violations).toEqual([]);
  });

  it("keeps ambient time, identity, and environment out of the inner layers", () => {
    const offenders = [...layer("domain"), ...layer("application")].flatMap(
      (file) =>
        ["process.env", "Date.now", "randomUUID"].some((token) =>
          codeOnly(file.contents).includes(token),
        )
          ? [file.path]
          : [],
    );

    expect(offenders).toEqual([]);
  });

  it("only lets infrastructure and main be the outermost layers", () => {
    expect(layer("main").length).toBeGreaterThan(0);
    expect(forbidden(layer("domain"), ["infrastructure"])).toEqual([]);
  });
});
```

```typescript
import type { Clock } from "../../src/application/ports/clock.js";
import type { EventPublisher } from "../../src/application/ports/event-publisher.js";
import type { IdGenerator } from "../../src/application/ports/id-generator.js";
import type { DomainEvent } from "../../src/domain/shared/domain-event.js";
import { buildHttpApp } from "../../src/infrastructure/http/fastify.js";
import { createInMemoryPaymentGateway } from "../../src/infrastructure/payments/in-memory-payment-gateway.js";
import {
  buildControllers,
  buildInMemoryDependencies,
  buildUseCases,
  type UseCases,
} from "../../src/main/container.js";

export const FIXED_NOW = "2026-01-01T00:00:00.000Z";

type TestEnvironmentOptions = {
  declinePayments?: boolean;
};

export type TestEnvironment = {
  /** The port implementations, including the shared outbox. */
  repositories: ReturnType<typeof buildInMemoryDependencies>;
  /** Events the publisher actually received; empty until the outbox drains. */
  published: DomainEvent[];
  useCases: UseCases;
  controllers: ReturnType<typeof buildControllers>;
  /** Drains pending outbox messages, as the background worker would. */
  drainOutbox: () => Promise<void>;
};

/**
 * Reuses the production wiring and overrides only the ports that tests care
 * about: a fixed clock, predictable ids, captured events, and a gateway that
 * can be told to decline. Same ports, different adapters.
 */
export function createTestEnvironment(
  options: TestEnvironmentOptions = {},
): TestEnvironment {
  const repositories = buildInMemoryDependencies();

  const clock: Clock = { now: () => FIXED_NOW };
  let sequence = 0;
  const ids: IdGenerator = { nextId: () => `id-${(sequence += 1)}` };

  const published: DomainEvent[] = [];
  const events: EventPublisher = {
    async publish(event) {
      published.push(event);
    },
  };

  const gateway = createInMemoryPaymentGateway(
    options.declinePayments === true ? { declineWhen: () => true } : {},
  );

  const useCases = buildUseCases({
    ...repositories,
    clock,
    ids,
    events,
    gateway,
  });

  return {
    repositories,
    published,
    useCases,
    controllers: buildControllers(useCases),
    async drainOutbox() {
      const result = await useCases.dispatchOutbox();

      if (!result.ok) {
        throw new Error(result.error.message);
      }
    },
  };
}

export function createTestHttpApp(options: TestEnvironmentOptions = {}) {
  const environment = createTestEnvironment(options);

  return {
    app: buildHttpApp({ controllers: environment.controllers, logger: false }),
    environment,
  };
}
```

```typescript
import { describe, expect, it } from "vitest";
```

```typescript
describe("in-memory rate limiter", () => {
  it("allows the limit and rejects the next request", async () => {
    const limiter = createInMemoryRateLimiter({
      limit: 2,
      windowSeconds: 60,
    });

    expect(await limiter.consume("ip:/checkout")).toMatchObject({
      allowed: true,
      remaining: 1,
    });
    expect(await limiter.consume("ip:/checkout")).toMatchObject({
      allowed: true,
      remaining: 0,
    });
    expect(await limiter.consume("ip:/checkout")).toMatchObject({
      allowed: false,
      remaining: 0,
    });
  });

  it("counts callers independently", async () => {
    const limiter = createInMemoryRateLimiter({ limit: 1, windowSeconds: 60 });

    expect((await limiter.consume("a:/checkout")).allowed).toBe(true);
    expect((await limiter.consume("b:/checkout")).allowed).toBe(true);
    expect((await limiter.consume("a:/checkout")).allowed).toBe(false);
  });

  it("resets when the window elapses", async () => {
    let clock = 1_000;
    const limiter = createInMemoryRateLimiter({
      limit: 1,
      windowSeconds: 10,
      now: () => clock,
    });

    expect((await limiter.consume("ip")).allowed).toBe(true);
    expect((await limiter.consume("ip")).allowed).toBe(false);

    clock += 10_000;

    expect((await limiter.consume("ip")).allowed).toBe(true);
  });
});
```

```typescript
import { describe, expect, it } from "vitest";
import {
  buildInMemoryDependencies,
  buildUseCases,
} from "../../../src/main/container.js";
import { err, ok } from "../../../src/domain/shared/result.js";
import { createMoney } from "../../../src/domain/product/money.js";
import { createProduct } from "../../../src/domain/product/product.js";
import { createInMemoryStore } from "../../../src/infrastructure/persistence/in-memory/store.js";
import { createInMemoryProductRepository } from "../../../src/infrastructure/persistence/repositories/in-memory-product-repository.js";
import { createInMemoryUnitOfWork } from "../../../src/infrastructure/transactions/in-memory-unit-of-work.js";

function sampleProduct(id: string) {
  const price = createMoney(1999, "usd");
  if (!price.ok) throw new Error("Expected money");

  const product = createProduct({
    id,
    name: "Keyboard",
    price: price.value,
    createdAt: "2026-01-01T00:00:00.000Z",
  });
  if (!product.ok) throw new Error("Expected a product");

  return product.value;
}

describe("in-memory unit of work", () => {
  it("commits every write when the work succeeds", async () => {
    const store = createInMemoryStore();
    const products = createInMemoryProductRepository(store);
    const unitOfWork = createInMemoryUnitOfWork(store);

    const result = await unitOfWork.execute(async () => {
      await products.save(sampleProduct("p-1"));
      await products.save(sampleProduct("p-2"));
      return ok("done");
    });

    expect(result).toEqual(ok("done"));
    expect(await products.findById("p-1")).not.toBeNull();
    expect(await products.findById("p-2")).not.toBeNull();
  });

  it("rolls back every write when the work returns a failure", async () => {
    const store = createInMemoryStore();
    const products = createInMemoryProductRepository(store);
    const unitOfWork = createInMemoryUnitOfWork(store);

    const result = await unitOfWork.execute(async () => {
      await products.save(sampleProduct("p-1"));
      return err({ type: "business_failure", message: "nope" });
    });

    expect(result.ok).toBe(false);
    if (result.ok) throw new Error("Expected a failure");
    expect(result.error.type).toBe("business_failure");
    expect(await products.findById("p-1")).toBeNull();
  });

  it("rolls back and reports transaction_failed when the work throws", async () => {
    const store = createInMemoryStore();
    const products = createInMemoryProductRepository(store);
    const unitOfWork = createInMemoryUnitOfWork(store);

    const result = await unitOfWork.execute(async () => {
      await products.save(sampleProduct("p-1"));
      throw new Error("connection reset");
    });

    expect(result.ok).toBe(false);
    if (result.ok) throw new Error("Expected a failure");
    expect(result.error).toEqual({
      type: "transaction_failed",
      message: "connection reset",
    });
    expect(await products.findById("p-1")).toBeNull();
  });

  it("rolls back a real use case when a later write fails", async () => {
    const dependencies = buildInMemoryDependencies();
    const failingInventory = {
      ...dependencies.inventory,
      async save(): Promise<void> {
        throw new Error("disk full");
      },
    };

    const useCases = buildUseCases({
      ...dependencies,
      inventory: failingInventory,
    });

    const created = await useCases.createProduct({
      name: "Keyboard",
      amountInMinorUnits: 1999,
      currency: "usd",
      availableQuantity: 5,
    });

    expect(created.ok).toBe(false);
    if (created.ok) throw new Error("Expected a failure");
    expect(created.error.type).toBe("transaction_failed");

    // The product row was written first, but the transaction undid it.
    const products = await dependencies.products.findAll();
    expect(products).toEqual([]);
    expect(await dependencies.inventory.findByProductId("id-1")).toBeNull();
  });
});
```
